# 常见禁忌与慎用场景

> 本页按“先排除高风险人群，再考虑补充剂”的顺序组织。若存在疾病诊断、处方药、妊娠/哺乳、儿童或手术计划，应优先进行专业评估。^[raw/references/safety-nccih-herbs-interactions.md]

## 一、生命阶段

| 人群 | 主要风险 | 常见需要避免/慎用的成分 |
|---|---|---|
| 妊娠/备孕 | 致畸风险、子宫收缩、证据不足 | 高剂量预成型维生素 A、黑升麻、圣约翰草、部分精油/草本浓缩物 |
| 哺乳期 | 乳汁转运、婴儿暴露、证据不足 | 多数草本浓缩物、镇静类草本、减重/排毒产品 |
| 婴幼儿/儿童 | 剂量窗口窄、误服风险 | 成人复合维生素、铁剂、褪黑素、兴奋/镇静类草本 |
| 老年人 | 多药共用、肾功能下降、跌倒风险 | 镇静类补充剂、高剂量镁/钾、抗凝相关草本 |

## 二、疾病状态

| 疾病/状态 | 需要重点排查 | 原因 |
|---|---|---|
| 肾功能不全 | 镁、钾、磷、高剂量维生素 C、蛋白粉 | 排泄能力下降，电解质或代谢负担增加 |
| 肝病或肝酶升高 | 绿茶提取物、黑升麻、卡瓦、复合“护肝/减重”草本 | 草本和浓缩提取物存在肝损伤报告或不确定性 |
| 出血性疾病/抗凝治疗 | 鱼油高剂量、姜黄素、大蒜、银杏、维生素 E 高剂量 | 可能增加出血风险或影响凝血管理 |
| 铁过载/血色病 | 铁补充剂、含铁复合维生素 | 可能加重铁负荷 |
| 甲状腺疾病 | 碘、海藻/海带浓缩物、钙/铁与左甲状腺素同服 | 碘过量可诱发甲状腺功能波动；矿物质影响药物吸收 |
| 肾结石风险 | 高剂量维生素 C、钙补充方式不当 | 需要结合结石类型、饮食钙和尿液指标判断 |
| 自身免疫病/移植后 | 紫锥菊、免疫刺激类草本 | 理论上可能影响免疫调节或抵消免疫抑制 |

## 三、手术前后

- 手术前应主动告知医生所有补充剂和草本产品。
- 可能影响出血、镇静、血糖或血压的补充剂，常需要术前停用一段时间；具体时间以医生和麻醉团队要求为准。
- 高风险例子：鱼油高剂量、姜黄素、大蒜、银杏、人参、圣约翰草、缬草、褪黑素等。

## 四、红旗产品

以下产品应默认高风险，除非有明确专业建议：

- 宣称“治疗/治愈癌症、糖尿病、高血压、脂肪肝”等疾病。
- “排毒、清肝、燃脂、壮阳、快速降糖/降压”等复合草本产品。
- 成分表不完整、剂量不透明、只写“专利混合物”的产品。
- 未经医生确认而与处方药叠加使用的草本浓缩物。
