# 药物-营养素相互作用

> 药物与营养素/草本之间的相互作用可能影响药物吸收、代谢或药效，也可能叠加出血、低血糖、高钾血症、镇静等不良反应风险。^[raw/references/safety-nccih-herbs-interactions.md]

## 高风险药物类别

| 药物类别 | 需要重点排查的补充剂 | 主要风险 |
|---|---|---|
| 抗凝/抗血小板药 | 维生素 K、Omega-3、姜黄素、大蒜、银杏、丹参类草本 | 抗凝效果波动或出血风险 |
| 降糖药/胰岛素 | α-硫辛酸、肉桂、铬、苦瓜/葫芦巴等草本 | 低血糖或血糖波动 |
| ACEI/ARB/保钾利尿剂 | 钾补充剂、高钾盐替代品 | 高钾血症 |
| 甲状腺素 | 钙、铁、镁、锌、膳食纤维 | 降低左甲状腺素吸收 |
| 抗生素/双膦酸盐 | 钙、铁、镁、锌等二价/三价矿物质 | 螯合导致吸收下降 |
| 免疫抑制剂 | 紫锥菊、免疫刺激类草本 | 理论上可能抵消免疫抑制 |
| 镇静/抗抑郁药 | 褪黑素、缬草、圣约翰草、5-HTP | 过度镇静、血清素相关风险或药物代谢改变 |
