# HMB (β-羟基-β-甲基丁酸)

> 亮氨酸的代谢产物，在身体受到质量负荷时内源性产生。作为运动补充剂，主要用于肌肉保护、减少运动引起的肌肉损伤和加速恢复。对老年人的肌少症（Sarcopenia）有潜在辅助价值。

## Overview

β-羟基-β-甲基丁酸（HMB, β-Hydroxy β-Methylbutyrate）是支链氨基酸亮氨酸在人体内经过两步代谢转化而来的产物。亮氨酸约占胁肌蛋白水解的 35%，其中约 5% 转化为 HMB。健康成年人每日内源性产生约 0.2–0.4 g HMB，从饮食中获取约 0.5 g。

当身体受到应激（如激烈运动、手术、疾病）时，胁肌蛋白分解加速，HMB 的内源性产生可能不足以完全保护肌肉组织。此时补充 HMB 可能有助于延缓蛋白分解并促进蛋白合成。

## Key Facts

| 项目 | 内容 |
|------|------|
| 化学名称 | 3-羟基-3-甲基丁酸 |
| 常见别名 | HMB、β-Hydroxy-β-Methylbutyrate |
| 先驱物 | 亮氨酸（Leucine） |
| 溶解性 | 水溶性（以钠盐或游离酸形式存在） |
| 常见形式 | HMB 钠盐（Ca-HMB）、HMB 游离酸 |
| 分子量 | 136.19 g/mol（游离酸） |

## Functions & Benefits

### 肌肉保护与运动恢复

HMB 在运动营养中的研究集中在减少肌肉损伤和加速恢复上：

- **运动引起的肌肉损伤**：部分研究表明，补充 HMB 可减少运动后肌酸激酶（CK）水平升高，减轻肌肉损伤程度（PMID 25795200）
- **力量恢复**：在接连进行的训练中，HMB 可能加速力量恢复和减少疲劳
- **对已训练运动员的效果**：在已有训练经验的运动员中，HMB 的益处可能不如新手明显，因为新手的肌肉蛋白分解更高

> **结论**：HMB 可能对减轻运动引起的肌肉损伤有帮助，但对运动表现的直接提升效果不如肌酸明确。

### 肌少症（Sarcopenia）与老年人

HMB 在老年人中的研究引起了广泛关注：

- **肌肉量保持**：多项研究表明，结合蛋白质补充和阻力训练，HMB 可增加老年人的瘦体重（PMID 20601741）
- **力量改善**：部分研究显示下肢力量有轻微改善
- **卡路里保持**：某些研究显示 HMB 可能有助于维护基础代谢率

> **结论**：对老年人的肌肉保护有中等趋势的积极证据，但最佳效果需要结合适当的蛋白质摄入和运动训练。

### 其他潜在益处

- **戒断期体重管理**：可能减少卡路里排划时的肌肉流失
- **病人患者**：可能延缓病人（如癌症患者）的肌肉消耗
- **长期卧床**：可能减少因不活动引起的肌肉萎缩

## Mechanisms

1. **抑制蛋白分解**：HMB 可能通过抑制泛素（ubiquitin）-蛋白酶体（proteasome）通路和减少肌肉蛋白酶（calpains）活性来减少蛋白分解
2. **促进蛋白合成**：通过 mTOR 信号通路促进肌蛋白合成
3. **抗炎作用**：减少炎症因子（TNF-α、IL-6）的释放，减轻炎症性肌肉损伤
4. **线粒体保护**：可能保护肌纤维的线粒体完整性

## Populations & Dosage

### 常见补充剂量

| 用途 | 常用剂量 | 备注 |
|------|----------|------|
| 肌肉保护 / 运动恢复 | 3 g/日 | 分 2–3 次服用，效果最好 |
| 老年肌少症 | 3 g/日 | 结合足够蛋白质摄入和运动训练 |
| 卡路里限制 / 减重 | 3 g/日 | 减少肌肉流失 |
| 肌肉损伤预防 | 1.5–3 g/日 | 运动前后服用 |

### 吸收优化

- **分次服用**：分 2–3 次服用（如每次 1 g）可保持血浓中 HMB 浓度稳定
- **与蛋白质联用**：蛋白质提供亮氨酸原料，可增强 HMB 效果
- **与运动训练结合**：运动刺激可增强蛋白合成对 HMB 的反应
- **Ca-HMB vs 游离酸**：钠盐形式更稳定，生物利用度与游离酸形式相似

### 高风险人群

- **老年人（50 岁+）**：肌少症预防和管理
- **长期卧床者**：减少肌肉萎缩
- **飨食限制者**：亮氨酸摄入不足时，HMB 可补充亮氨酸的代谢效益
- **初级运动员**：对新开始训练的人群益处可能更大
- **病人和医疗手术恢复者**：可能有助于减少肌肉消耗

## Safety

### 安全性概览

HMB 被广泛认为是安全的，研究中使用较高剂量（6 g/日）也很少出现严重副作用：

- **常见副作用**（通常轻微）：
  - 胃部不适、肠胀气
  - 腹泻（稀见）
  - 头痛

- **安全剂量范围**：常规使用 3 g/日，研究中使用过 6 g/日，未发现显著不良反应

### 药物相互作用

- 目前未发现与常见药物的重大相互作用
- 理论上可能与降胆固醇药物产生微弱互作用（因其与亮氨酸相关）

### 禁忌与注意事项

- 对 HMB 或亮氨酸过敏者禁用（极罕见）
- 孕妇和哺乳期：安全性数据有限，建议使用前咨询医生
- 前列腺病变或前列腺肿瘤：亮氨酸/支链氨基酸代谢与前列腺病理有关，HMB 的影响不明确，建议谨慎

## Forms & Bioavailability

| 形式 | 特点 | 生物利用度 |
|------|------|-----------|
| **HMB 钠盐 (Ca-HMB)** | 最常见、稳定、成本较低 | 高 |
| **HMB 游离酸** | 无钠放入，遢渗透性更好 | 高 |
| **HMB 亮氨酸复合剂** | HMB + 亮氨酸组合 | 高 |

### 食物来源

| 食物 | 特点 |
|------|------|
| 红肉 | 亮氨酸来源，可转化为 HMB |
| 鸡蛋 | 富含亮氨酸 |
| 鱼类 | 亮氨酸来源 |
| 奶制品 | 含有亮氨酸，可转化为 HMB |

> 食物中的亮氨酸可转化为 HMB，但转化率仅约 5%，难以通过饮食达到补充剂剂量。

## Quality & Standards

- 优先选择 HMB 钠盐或游离酸形式
- 查看含量标注是否为 HMB 本身，而非亮氨酸
- 第三方检测确保含量准确性
- 注意亮氨酸与 HMB 的区别：亮氨酸需要 20 g 以上才能提供等效的 HMB
