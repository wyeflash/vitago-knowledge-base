# 硫辛酸 (Alpha-Lipoic Acid)

> 内源性含硫脂肪酸，兼具水溶性与脂溶性，是线粒体能量代谢的关键辅因子，同时具有强效抗氧化能力，常用于糖代谢支持与神经保护。

## Overview

硫辛酸（Alpha-Lipoic Acid, ALA）是一种由人体少量合成的含硫脂肪酸，在线粒体丙酮酸脱氢酶和 α-酮戊二酸脱氢酶复合体中作为必需辅因子参与能量代谢。它具有独特的水溶性与脂溶性双重特性，使其能够在细胞内外及不同组织中发挥抗氧化作用。膳食来源包括红肉、动物肝脏和菠菜，但含量较低。

## Key Facts

| 项目 | 内容 |
|------|------|
| 化学名称 | (R)-1,2-二硫戊环-3-戊酸 |
| 常见别名 | ALA、硫辛酸、α-硫辛酸 |
| 溶解性 | 水溶性与脂溶性兼具（两亲性） |
| 活性形式 | (R)-硫辛酸（天然形式） |
| 合成部位 | 线粒体（人体可少量合成） |
| 主要来源 | 红肉、动物肝脏、菠菜、西兰花、酵母 |
| 分子量 | 206.33 g/mol |

## Functions & Benefits

### 抗氧化作用

硫辛酸是强效的抗氧化剂，其作用机制包括：

- **直接清除自由基**：可中和活性氧（ROS）和活性氮（RNS）
- **再生其他抗氧化剂**：可还原被氧化的谷胱甘肽、维生素 C 和维生素 E，使其恢复活性
- **螯合金属离子**：可与铜、铁、锌等过渡金属离子结合，减少其促氧化作用

### 糖代谢与胰岛素敏感性

硫辛酸在糖代谢中扮演多重角色：

- **AMPK 激活**：可激活 AMP 活化蛋白激酶（AMPK），促进葡萄糖摄取和利用
- **胰岛素信号通路**：增强胰岛素受体底物（IRS）的酪氨酸磷酸化，改善胰岛素敏感性
- **临床试验证据**：多项 RCT 显示，600–1,800 mg/日的硫辛酸可改善 2 型糖尿病患者的胰岛素敏感性和空腹血糖（PMID 12643111）

> **结论**：硫辛酸对糖代谢的改善有中等强度证据，但不能替代标准降糖治疗。

### 糖尿病神经病变

硫辛酸在糖尿病周围神经病变（DPN）中的研究最为充分：

- **ALADIN 研究**：600 mg/日静脉注射硫辛酸可显著改善糖尿病神经病变症状和神经传导速度
- **NATHAN 1 研究**：长期口服 600 mg/日对早期神经病变有保护作用
- **SYDNEY 试验**：证实了对神经病变症状（疼痛、麻木、烧灼感）的显著改善
- **作用机制**：通过改善神经血流、减少氧化应激和晚期糖基化终产物（AGEs）积累

> 欧洲和德国的指南已将硫辛酸列为糖尿病神经病变的推荐辅助治疗手段。

### 其他研究中的潜在益处

- **认知功能**：动物研究显示神经保护作用，人体证据有限
- **心血管保护**：通过减少氧化应激和炎症标志物可能具有辅助益处
- **体重管理**：部分研究显示可能轻微促进减重，但效应量很小

## Mechanisms

1. **线粒体能量代谢**：作为丙酮酸脱氢酶和 α-酮戊二酸脱氢酶的辅因子，参与三羧酸循环
2. **抗氧化网络核心**：还原氧化型谷胱甘肽（GSSG → GSH），间接增强细胞内总抗氧化能力
3. **AMPK 信号通路**：激活 AMPK，促进 GLUT4 转位和葡萄糖摄取
4. **NF-κB 抑制**：减少炎症因子表达
5. **AGEs 抑制**：减少晚期糖基化终产物的形成

## Populations & Dosage

### 常见补充剂量

| 用途 | 常用剂量 | 备注 |
|------|----------|------|
| 一般保健 / 抗氧化 | 100–300 mg/日 | 适合健康成年人 |
| 血糖管理 | 300–600 mg/日 | 分 1–2 次服用 |
| 糖尿病神经病变 | 600–1,800 mg/日 | 德国常用 600 mg/日；部分方案使用静脉注射 |
| 神经保护 | 300–600 mg/日 | 证据中等 |

### 吸收优化

- **空腹 vs 随餐**：空腹吸收率更高，但可能引起胃部不适；随餐服用可减少胃肠刺激但吸收略降
- **(R)-型 vs 外消旋**：(R)-硫辛酸是天然活性形式，生物利用度高于合成外消旋混合物（R/S 各 50%）
- **钠盐形式**：R-硫辛酸钠盐的生物利用度可能优于游离酸形式

### 高风险人群

- **2 型糖尿病患者**：可能受益于血糖控制和神经病变改善
- **糖尿病神经病变患者**：有最充分的临床证据支持
- **老年人**：内源性合成能力下降，抗氧化需求增加
- **素食者**：膳食摄入可能较低

## Safety

### 安全性概览

硫辛酸被广泛认为是安全的补充剂，长期研究未报告严重不良反应：

- **常见副作用**（通常轻微）：
  - 恶心、胃部不适、腹泻（尤其空腹服用时）
  - 皮疹、瘙痒
  - 低血糖症状（糖尿病患者需监测血糖）
  - 硫样体味（由于含硫结构）

### 药物相互作用

| 药物类别 | 相互作用 | 建议 |
|----------|----------|------|
| **降糖药 / 胰岛素** | 硫辛酸可能增强降糖效果，增加低血糖风险 | 密切监测血糖，必要时调整药物剂量 |
| **左旋甲状腺素** | 理论上可能干扰甲状腺激素替代治疗 | 甲状腺功能减退者慎用，间隔服用 |
| **化疗药物** | 抗氧化剂可能干扰某些化疗药机制 | 癌症患者应在医生指导下使用 |
| **华法林** | 理论上可能影响凝血 | 监测 INR |

### 禁忌与注意事项

- 对硫辛酸过敏者禁用
- 甲状腺功能减退患者慎用（可能影响甲状腺激素代谢）
- 孕妇和哺乳期：安全性数据不足，建议避免大剂量补充
- 手术前 2 周建议停用

## Forms & Bioavailability

| 形式 | 特点 | 生物利用度 |
|------|------|-----------|
| **外消旋硫辛酸 (R/S)** | 最常见、成本最低 | 中等 |
| **(R)-硫辛酸** | 天然活性形式 | 较高（约为外消旋的 1.5–2 倍） |
| **R-硫辛酸钠盐** | 更稳定，吸收更好 | 较高 |
| **缓释制剂** | 延长吸收时间，减少胃肠刺激 | 与即释相当或略低 |

## Quality & Standards

- 优先选择标注为 "Stabilized (R)-Lipoic Acid" 或 "Na-R-ALA" 的产品
- 硫辛酸对光和热敏感，注意储存条件（避光、阴凉）
- 查看第三方检测认证（USP、NSF）
