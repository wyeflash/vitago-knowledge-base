# 褪黑素 (Melatonin)

> 由松果体在暗暖环境中分泌的脆色胺类激素，是人体主要的昼夜节律调节物质。临床研究支持其在失眠、倒时差和某些妊娠年龄群体中的应用。大剂量不等同于更好的效果。

## Overview

褪黑素（Melatonin）是由色氨酸转化而来的脆色胺类激素，主要由松果体在夜间分泌，光照会抑制其产生。它在调控睡眠-唤醒周期、季节性生理调节、免疫功能和抗氧化防御中发挥核心作用。年龄增长会导致内源性褪黑素分泌逐渐减少，影响睡眠质量。

褪黑素可通过人工合成或动物松果体提取获得。由于它在欧洲部分国家需要处方，在美国则作为非处方膳食补充剂广泛可获。

## Key Facts

| 项目 | 内容 |
|------|------|
| 化学名称 | N-乙酰-5-甲氧基色胺 |
| 常见别名 | 退黑素、松果体素、MT |
| 分泌规律 | 暗期分泌达峰，光照抑制 |
| 半衰期 | 30–50 分钟（口服） |
| 膳食来源 | 酸樱桃、小米、牛奶、核桃 |
| 分子量 | 232.28 g/mol |
| 受体 | MT1、MT2（视下庞核） |

## Functions & Benefits

### 睡眠调节

褪黑素是证据最充分的睡眠补充剂，对多种睡眠障碍有辅助作用：

- **失睡症**：多项系统综述表明，0.5–5 mg 的褪黑素可减少入睡时间、提高睡眠效率，尤其对老年人效果更明显（PMID 26715231）
- **睡眠质量**：对总睡眠时间和睡眠效率有一定影响，但对睡眠结构（深睡眠比例）的改善有限
- **早醒**：小剂量可帮助调整早睡早起型人群的作息

> **关键观点**：褪黑素对失眠的作用中等且不如处方睡眠药强劲。小剂量（0.3–1 mg）与大剂量（5–10 mg）效果相似，更高剂量不一定更有效。

### 倒时差（Jet Lag）

- 褪黑素被先进医学会（ACP）和劳伦斯飞行实用指南推荐用于倒时差管理
- 在目的地相当于夜间时服用，可加速适应新时区
- 对东向飞行过 5 个时区以上的人群最有效

### 轮班工作人群

- 夜班工作者的睡眠困难和日间睡眠质量下降是重要的公共卫生问题
- 褪黑素可帮助调整作息，提高白天的睡眠质量（尤其在暗光环境下）
- 轮班前后服用可以辅助时相调整

### 抗氧化与免疫

- 褪黑素是强效的溳水性抗氧化剂，可直接清除自由基
- 可增强谷胱甘肽过氧化酶（GPx）活性
- 调控免疫细胞因子产生，具有抗炎作用
- 免疫调控作用具有季节性变化：冬季免疫功能较强，夏季较弱

### 生殖健康

- **卵巢保备**：褪黑素可能通过抗氧化作用保护卵子和精子免受氧化损伤
- **辅助生殖**：部分研究表明可改善卵子质量和胚胎着床率
- **孕妇**：对妊娠期睡眠和日夜节律调控可能有帮助

## Mechanisms

1. **视下庞核受体**：褪黑素与 MT1 和 MT2 受体结合，抑制交感神经元活性，促进睡眠起始
2. **SCN 调节**：作用于视交叉上核（SCN），调整主时钟的时相
3. **抗氧化**：清除自由基，保护线粒体 DNA 免受氧化损伤
4. **免疫调控**：调节 T 细胞和自然杀伤细胞活性
5. **温度调节**：通过作用于视下庞核下丘脑，调控体温调节机制

## Populations & Dosage

### 常见补充剂量

| 用途 | 常用剂量 | 备注 |
|------|----------|------|
| 失眠症 | 0.3–5 mg（睡前 30–60 分钟） | 小剂量（0.3–1 mg）效果与大剂量类似 |
| 倒时差 | 0.5–5 mg（目的地睡前） | 东向飞行 5+ 时区效果最好 |
| 轮班工作者 | 1–3 mg（白天睡前 30 分钟） | 在暗光环境下服用 |
| 老年人睡眠障碍 | 0.3–2 mg | 老年人对低剂量反应更好 |
| 子宫肌瘤支持 | 2–10 mg | 在辅助生殖领域中使用 |

> **重要提示**：更高剂量（5–10 mg 或更高）不等同于更快或更好的睡眠，可能只会增加不良反应风险。

### 吸收优化

- **服用时间**：睡前 30–60 分钟服用效果最佳
- **口服吸收**：吸收率约 30–50%，受首过效应影响
- **合理日光曝露**：白天的光照曝露（尤其是户外）可增强天然褪黑素节律
- **屏蔽蓝光**：睡前 1–2 小时避免电子屏幕可促进内源性褪黑素分泌

### 高风险人群

- **老年人**：内源性褪黑素分泌随年龄减少，是低剂量补充的最佳人群
- **倒时差旅行者**：跨时区飞行的常见辅助手段
- **轮班工作者**：需要调整作息的人群
- **失眠症患者**：特别是睡眠起始困难者
- **自闭症谱系障碍**（ASD）：部分研究探索中
- **孕妇**：低至中剂量通常安全

## Safety

### 安全性概览

褪黑素在短期内（13 周以内）被认为是安全的，长期安全性数据较少：

- **常见副作用**（通常轻微）：
  - 困乏、晕眩、头痛
  - 恶心
  - 清晨时分痴呆（hangover 效果）
  - 多梦或惊叹
  - 低温（可能与体温调节作用有关）

### 药物相互作用

| 药物类别 | 相互作用 | 建议 |
|----------|----------|------|
| **血管收缩药** | 褪黑素可能增强血管收缩药效果 | 高血压患者监测血压 |
| **抗凝血药** | 可能增加出血风险 | 服用抗凝血药者需谨慎 |
| **镇静剂 / 睡眠药** | 协同作用，可能加深镇静效果 | 合用时注意不要超过推荐剂量 |
| **粮票抑制剂 (MAOIs)** | 可能增加褪黑素效果 | 合用时注意 |
| **口服避孕药** | 褪黑素可能影响激素代谢 | 长期合用时建议咨询医生 |
| **降糖药** | 可能影响胰岛素分泌 | 糖尿病患者监测血糖 |

### 禁忌与注意事项

- **自动免疫疾病**：原则上避免使用（可能刺激免疫系统）
- **抑郁症**：可能加重抑郁症状，但证据不一致
- **驾驶和操作机械**：服用后可能引起晕眩，避免在需要注意力的活动前服用
- **青春期前后儿童**：长期安全性数据不足，应尽量避免
- **不宕使用**：尽量避免长期连续服用，建议定期休止

## Forms & Bioavailability

| 形式 | 特点 | 生物利用度 |
|------|------|-----------|
| **速释片剂** | 快速溶出，适合快速入睡 | 中等 |
| **缓释制剂** | 慢速释放，维持整夜 | 较好（特定人群） |
| **含服片剂** | 经口腔黏膜吸收，避免首过效应 | 较高 |
| **液体剂型** | 剂量可灵活调整 | 中等 |
| **外用膏剂** | 用于皮肤保护和可能的免疫调控 | 局部 |

### 食物来源

| 食物 | 特点 |
|------|------|
| 酸樱桃、樱桃 | 含有较高水平的色氨酸（褪黑素前体） |
| 小米、澳洲坚果 | 含有色氨酸 |
| 牛奶 | 含有较少量褪黑素 |
| 素食 | 含有柔心里的小量褪黑素（作为手段不可靠） |

> 食物中褪黑素或其前体的含量较低，难以达到改善睡眠所需的剂量。

## Quality & Standards

- 选择纯度达标的合成褪黑素（动物来源产品已减少）
- 第三方检测：确保含量准确性
- 注意：某些产品实际含量与标签不符（建议选择经过第三方检测的品牌）
