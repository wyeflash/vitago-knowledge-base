# L-精氨酸（L-Arginine）

> 一氧化氮（NO）合成的前体氨基酸，理论上可通过血管舒张增加运动肌肉的血流。但作为单一成分的急性运动促力剂，证据一致性较弱；L-瓜氨酸可能是更高效的替代前体。

## Overview

L-精氨酸是一种条件必需氨基酸，在成人中通常可由饮食和内源性合成满足需求，但在应激、创伤或剧烈运动状态下可能不足。它是尿素循环和一氧化氮（NO）合成通路的关键底物。在运动营养领域，L-精氨酸被广泛用于预训练补剂，旨在通过 NO 介导的血管舒张增强运动表现和肌肉泵感。

## Key Facts

| 项目 | 内容 |
|------|------|
| 化学类别 | 条件必需氨基酸（碱性氨基酸） |
| 自然来源 | 红肉、禽肉、鱼类、奶制品、坚果、豆类 |
| 常见形式 | L-精氨酸游离碱、L-精氨酸盐酸盐、AAKG（α-酮戊二酸精氨酸） |
| 每日需要量 | 约 2–3 g（可内源合成 + 膳食获取） |
| 主要代谢通路 | 尿素循环、一氧化氮合成、肌酸合成、蛋白质合成 |

## Functions & Benefits

### 一氧化氮通路（理论核心）

L-精氨酸是内皮型一氧化氮合酶（eNOS）的底物，可转化为 NO 和瓜氨酸。NO 作为强效血管舒张因子：^[raw/guidelines/arginine-sports-performance-reviews.md]

- 理论上增加骨骼肌血流量
- 可能改善营养物质输送和代谢废物清除
- 与训练中的 "肌肉泵感"（muscle pump）相关

### 运动表现证据

现有系统综述的评估结论：^[raw/guidelines/arginine-sports-performance-reviews.md]

- **急性补充**：单次服用 3–6 g 对高强度、短时长运动表现的提升证据不一致
- **亚极量耐力**：部分研究显示可能延长力竭时间，但效应量不大
- **恢复与适应**：慢性补充可能对血流恢复和延迟性肌肉酸痛（DOMS）有轻微帮助
- **整体评价**：作为单一成分的急性促力效果不如肌酸或咖啡因明确

### 其他生理功能

- **免疫功能**：淋巴细胞增殖和细胞因子生成的底物
- **伤口愈合**：参与胶原蛋白合成和血管新生
- **生长激素**：部分研究提示大剂量可能短暂刺激 GH 分泌，但对运动表现的实际意义有限
- **肌酸合成**：与甘氨酸、甲硫氨酸共同合成肌酸

## Mechanisms

1. **NO 介导的血管舒张**：L-精氨酸 → eNOS → NO → cGMP → 血管平滑肌松弛 → 血流增加
2. **蛋白质合成信号**：参与 mTOR 通路的调节
3. **激素调节**：可能通过抑制生长抑素间接影响生长激素释放
4. **氨解毒**：作为尿素循环底物参与氨的清除

## Populations & Dosage

### 常见补充剂量

| 用途 | 剂量 | 备注 |
|------|------|------|
| 运动表现（急性） | 3–6 g | 运动前 60–90 分钟 |
| 运动表现（慢性） | 3–9 g/日 | 分 2–3 次服用，持续 2–8 周 |
| 一般健康支持 | 2–3 g/日 | 作为氨基酸补充 |

### 与 L-瓜氨酸的比较

| 特性 | L-精氨酸 | L-瓜氨酸 |
|------|----------|----------|
| 首过代谢 | 高（肝脏大量提取） | 极低（绕过肝脏） |
| 血浆精氨酸提升 | 中等 | 更高且更持久 |
| 运动促力证据 | 不一致 | 略优于精氨酸 |
| 胃肠道耐受性 | 高剂量易不适 | 更好 |

> **实践建议**：若以 NO 介导的运动收益为目标，L-瓜氨酸（或瓜氨酸苹果酸）可能是比 L-精氨酸更高效的选择。

## Safety & Precautions

### 常见副作用

- 胃肠道不适、腹泻、恶心（尤其 >6 g 单次剂量）
- 低血压风险（与降压药或 PDE5 抑制剂联用时）
- 电解质紊乱（罕见）

### 禁忌与注意

- **疱疹病毒感染者**：精氨酸可促进病毒复制，活动期应避免大剂量补充
- **低血压患者**：可能加重低血压症状
- **手术前后**：建议停用，因可能影响血压调节
- **药物相互作用**：与硝酸酯类、西地那非等联用可能导致血压过低

## Forms & Delivery

| 形式 | 特点 |
|------|------|
| L-精氨酸游离碱 | 最常见形式，味苦，溶解性一般 |
| 精氨酸盐酸盐 | 溶解性更好，可能胃肠道刺激略大 |
| AAKG（α-酮戊二酸精氨酸） | 声称增强吸收，但缺乏高质量对比证据 |
| L-瓜氨酸 | 更优的 NO 前体替代方案 |
