# 营养素索引

> 营养素实体页面索引。此目录仅收录经典营养学意义上的宏量营养素、维生素、矿物质、脂肪酸等。运动表现、睡眠、关节、代谢等用途不作为实体主分类；相关使用场景通过标签、概念页和指引页交叉引用。

## 维生素

- [维生素 A](vitamin-a) — 脂溶性维生素，视觉、免疫与细胞增殖
- [维生素 B1 / 硫胺素](thiamin) — 水溶性维生素，能量代谢与神经传导
- [维生素 B2 / 核黄素](vitamin-b2) — 水溶性维生素，能量代谢与细胞呼吸
- [维生素 B3 / 烟酸](niacin) — 水溶性维生素，NAD/NADP 前体，能量代谢与血脂调节
- [维生素 B5 / 泛酸](pantothenic-acid) — 水溶性维生素，CoA 组成部分，能量代谢
- [维生素 B6 / 吡哪醇](vitamin-b6) — 水溶性维生素，PLP 活性形式，氨基酸代谢与神经递质
- [生物素 / 维生素 B7](biotin) — 水溶性维生素，羰化酶辅因子
- [叶酸 / 维生素 B9](folate) — 一碳单位代谢、DNA 合成与孕期神经管缺陷预防
- [胆碱](choline) — 类维生素营养素，乙酰胆碱前体，神经递质与脂质代谢
- [维生素 B12](vitamin-b12) — 钢胺素，神经鞘形成、红细胞生成、DNA 合成
- [维生素 C](vitamin-c) — 水溶性维生素，胶原合成、抗氧化、免疫支持
- [维生素 D](vitamin-d) — 脂溶性维生素，骨骼健康、免疫调节
- [维生素 E](vitamin-e) — 脂溶性维生素，抗氧化、细胞膜保护
- [维生素 K2](vitamin-k2) — 脂溶性维生素，骨骼代谢与钙引导

## 矿物质

- [钙](calcium) — 人体含量最丰富的矿物质，骨骼与牙齿结构、肌肉收缩、神经传递
- [镁](magnesium) — 参与 300+ 酶反应，骨骼健康、心血管、肌肉与神经功能
- [铁](iron) — 必需微量矿物质，血红蛋白核心成分，氧运输、能量代谢、免疫功能
- [锌](zinc) — 必需微量矿物质，免疫防御、蛋白质与 DNA 合成、伤口愈合
- [磷](phosphorus) — 必需宏量矿物质，骨骼与能量代谢
- [钾](potassium) — 必需矿物质，细胞内外液平衡与心血管功能
- [铜](copper) — 必需微量矿物质，铁代谢与抗氧化
- [铬](chromium) — 微量矿物质，碳水代谢与胰岛素敏感性
- [碘](iodine) — 必需微量矿物质，甲状腺激素合成、大脑发育与代谢率调节
- [灒](selenium) — 必需微量矿物质，谷胱甘肽过氧化物酶与甲状腺激素脱碘酶
- [锰](manganese) — 必需微量矿物质，骨骼发育、能量代谢与抗氧化
- [钼](molybdenum) — 必需微量矿物质，硫代谢与某些酶反应
- [硼](boron) — 微量矿物质，骨骼健康与大脑功能
- [氟](fluoride) — 微量矿物质，牙齿璀璃质与骨骼强度

## 脂肪酸

- [Omega-3](omega-3) — 多不饱和脂肪酸（ALA/EPA/DHA），心血管健康、认知与抗炎

## 宏量营养素

- [蛋白质](protein) — 宏量营养素，肌肉合成、组织修复、酶催化、免疫防御与能量供应
- [碳水化合物](carbohydrates) — 宏量营养素，人体主要能量来源，大脑葡萄糖最低需求、糖原储备与血糖调节
- [脂肪 / 脂质](fats) — 宏量营养素，能量密度最高的营养素，细胞膜结构、脂溶性维生素载体、激素与类花生酸前体
