# 生物素（维生素 B7 / H）

> 生物素是水溶性 B 族维生素，作为羰化酶的辅酶参与脂质、糖和蛋白质的代谢。它在体内由肠道菌群合成，实际需求量较小。

## Overview

生物素以羰化生物素（biocytin）为活性形式，作为五种羰化酶的辅基参与脂肪酸的合成、分解和糖的新陈代谢。它在几乎所有食物中都存在，缺乏极为罕见，但某些人群（如生牛蛋白大量摄入者）可能缺乏。^[raw/guidelines/nih-ods-biotin-hp.md]

## Key Facts

| 项目 | 内容 |
|------|------|
| 别名 | 维生素 B7、维生素 H、辅酶 R |
| 溶解性 | 水溶性 |
| 活性形式 | 羰化生物素 (Biocytin) |
| 主要来源 | 蛋黄、肝脏、肉类、树宁、花榨、苋茗、野生菌菇 |
| 吸收部位 | 小肠（主动转运） |
| 内源性合成 | 肠道菌群可合成，但量不足以满足需求 |

## Functions & Benefits

### 能量代谢
- 作为羰化酶的辅酶参与肪肪酸、丙酮酸和支链肪肪酸的代谢
- 参与糖的新陈代谢

### 蛋白质代谢
- 参与某些氨基酸的代谢（亮氨酸、异亮氨酸）
- 支持某些酶的活化

### 皮肤、头发和指甲健康
- 常被用于护发和护肤产品中
- 缺乏可导致皮炎、脱发和指甲脆弱

### 细胞信号
- 参与细胞增殖、DNA 修复和基因表达的调控

## Mechanisms

1. **羰化反应**：生物素作为五种羰化酶的辅基，参与脂肪酸的合成、分解和糖的新陈代谢。
2. **细胞增殖**：生物素参与细胞增殖的调控，可能影响肠道粘膜健康和免疫功能。
3. **受体信号**：生物素可能影响某些转录因子的活性，调控基因表达。

## Safety

### 安全上限（UL）

目前未设定生物素的可耐受上限量（UL）。

### 过量风险
- 水溶性维生素，过量时从尿液排出
- 极高剂量很少引起严重不良反应

### 药物互作用
- **生物素抵死**：生牛蛋白中含有生物素绑合蛋白 avidin，可阻止生物素吸收（熔煮可破坏）
- **抗痘药**：长期服用抗痘药（如卡马西平、苯妥英钠）可能增加缺乏风险
- **抗皮肤药达法拉淡** (Targretin)：可能导致生物素缺乏
