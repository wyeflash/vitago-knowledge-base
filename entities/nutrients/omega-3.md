# Omega-3 脂肪酸

> 一组多不饱和脂肪酸，主要包括 ALA、EPA 和 DHA，对心血管、认知、免疫和胎儿发育具有重要意义。

## Overview

Omega-3 脂肪酸（ω-3 fatty acids）是人体必需但无法自行合成的多不饱和脂肪酸，必须通过饮食或补充剂获取。主要包括：
- **ALA**（α-亚麻酸，C18:3n-3）：短链，来自植物油
- **EPA**（二十碳五烯酸，C20:5n-3）：长链，来自海鱼
- **DHA**（二十二碳六烯酸，C22:6n-3）：长链，来自海鱼

ALA 可在体内转化为 EPA 和 DHA，但转化率很低（<5%）。直接获取 EPA/DHA 主要依赖海鱼或补充剂。^[raw/guidelines/nih-ods-omega-3-health-professional-2024.md]

## Key Facts

| 项目 | 内容 |
|------|------|
| 化学类别 | 多不饱和脂肪酸 (PUFA) |
| 主要来源 | 深海鱼类、鱼油补充剂、亚麻籽/奇亚籽/胡桃（ALA） |
| 必需性 | 必需脂肪酸（ALA 为必需，EPA/DHA 为条件必需） |
| 储存位置 | 细胞膜磷脂（DHA 在脑部和视网膜中富集） |
| AMDR | 0.6%–1.2% 总能量（ALA），其中 EPA/DHA 可占 AMDR 的约 10% |

## Functions & Benefits

### 心血管健康
- 高剂量 EPA/DHA（如 IPE 4 g/日）可显著降低心血管事件风险（REDUCE-IT 试验）^[raw/guidelines/nih-ods-omega-3-health-professional-2024.md]
- 降低血温三酸甘油酯（TG）水平
- 改善血管内皮功能
- 注意：不同研究结果不一致，可能与剂量、研究人群、背景饮食和他汀类使用有关

### 认知与神经发育
- DHA 是大脑和视网膜的主要结构性脂质
- 孕期和婴幼期 DHA 摄入与神经发育相关
- 系统综述对孕妇补充 EPA/DHA 的认知发展效果结论不一致

### 抗炎与免疫
- EPA 是前列腺素前体，可转化为抗炎性介质（保护素、白三烯等）
- 调节酸酸代谢，平衡促炎与抗炎反应
- 高剂量（900 mg EPA + 600 mg DHA/日或更高）可能抑制炎症反应

### 孕产与胎儿健康
- 长链 Omega-3 补充剂（尤其 DHA）可降低早产和极早产风险
- 2018 Cochrane 系统综述（70 RCTs, 19,927 名孕妇）评估了孕期 Omega-3 补充的母婴结局^[raw/guidelines/nih-ods-omega-3-health-professional-2024.md]

## Safety

### 安全上限

IOM 未建立 Omega-3 的 UL。但以下权威机构提供了安全参考：^[raw/guidelines/nih-ods-omega-3-health-professional-2024.md]

| 机构 | 安全上限 |
|------|----------|
| EFSA | EPA+DHA 合计高达约 5 g/日的长期补充似乎安全，未显示出血问题或免疫功能、葡萄糖平衡或脂质过氧化受影响 |
| FDA | 膳食补充剂中 EPA+DHA 最高 5 g/日安全（含处方鱼油药物） |

### 常见不良反应

副作用通常轻微，包括：^[raw/guidelines/nih-ods-omega-3-health-professional-2024.md]
- 不愉快的味道
- 口臭
- 胃烧心
- 恶心
- 胃肠不适
- 腹泻
- 头痛
- 汗臭

### 出血风险
- EPA/DHA 2–15 g/日可能通过减少血小板聚集延长出血时间
- 2014 年系统综述结论：Omega-3 不影响临床显著出血风险
- 手术前建议暂停高剂量补充剂

### 免疫抑制
- 900 mg EPA + 600 mg DHA/日或更高剂量持续数周可能降低免疫功能（抑制炎症反应）

## Forms & Bioavailability

| 剂型 | 特点 |
|------|------|
| 乙酯化形 (EE) | 成本较低，需脂肪协助吸收 |
| 甘油三酯形 (TG) | 自然形式，吸收率更高 |
| 磷脂形 (PL) | 某些研究表明吸收优于 TG（存在争议） |
| 磷脂质体 (rTG) | 重新酯化甘油三酯，吸收率较高 |

## Interactions

### 药物相互作用

- **华法林（Warfarin）及类似抗凝血药**：高剂量鱼油可能具有抗血小板作用，但效力低于阿司匹林。可能延长凝血时间（INR 升高），但大多数研究表明 3–6 g/日鱼油通常不显著影响华法林使用者的抗凝血状态。2014 年系统综述结论：Omega-3 不影响临床显著出血风险。FDA 批准的鱼油药物说明书表示，研究未显示鱼油与华法林或阿司匹林联合使用时出血风险增加。^[raw/guidelines/nih-ods-omega-3-health-professional-2024.md]

### 其他相互作用
- **降血压药**：可能协同降低血压
- **维生素 E**：高剂量可能影响维生素 E 代谢
