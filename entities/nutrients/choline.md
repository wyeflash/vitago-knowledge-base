# 胶碱 (Choline)

> 胶碱是一种必需营养素，参与神经递质乙酰胆碱的合成、脂质代谢和细胞膜结构的维护。2018 年 NASEM 将其列为必需营养素并设定 AI。

## Overview

胶碱是一种必需营养素，虽然在体内可以由甲基化合成，但合成量不足以满足需求。胶碱是乙酰胆碱的前体，乙酰胆碱是关键神经递质；同时胶碱是磷脏脂质的前体，参与细胞膜的结构维护。对胎儿脑部发育至关重要。^[raw/guidelines/nih-ods-choline-hp.md]

## Key Facts

| 项目 | 内容 |
|------|------|
| 分类 | 必需营养素（类维生素营养素） |
| 溶解性 | 水溶性，带有脂溶性特点 |
| 前体 | 磷脏胆碱、磷脏丝氨酸 |
| 主要来源 | 鸡蛋、牛肝、大豆、花生、鱼肉、十字花菜、牛奶 |
| 吸收部位 | 小肠（主动转运） |
| 内源性合成 | 可以由甲基化合成，但合成量不足 |

## Functions & Benefits

### 神经递质合成
- 乙酰胆碱是关键的神经递质，参与记忆、学习和肌肉控制
- 胶碱是乙酰胆碱的前体

### 脂质代谢
- 参与磷脏胆碱和磷脏脂肪酸的合成
- 维护细胞膜的磷脏双分子层结构

### DNA 合成与表达
- 作为甲基化的甲基供体，参与表遗传学调控
- 对胎儿脑部发育至关重要

### 肝脏功能
- 参与脂质的运输，防止脂肪在肝脏中堆积
- 缺乏可导致脂肪肝

## Mechanisms

1. **乙酰胆碱合成**：胶碱在神经元中被转化为乙酰胆碱，是记忆和运动控制的关键递质。
2. **磷脏脂质代谢**：胶碱作为磷脏脂质的前体，参与细胞膜的结构与信号传导。
3. **甲基化**：胶碱提供甲基团，参与 DNA 和组蛋白的甲基化修饰，影响基因表达。
4. **脂质转运**：胶碱参与肝脏脂质的运输，防止非酒精性脂肪肝（NAFLD）的发生。

## Safety

### 安全上限（UL）

| 年龄 | UL |
|------|-----|
| 1-3 岁 | 1,000 mg |
| 4-8 岁 | 1,000 mg |
| 9-13 岁 | 2,000 mg |
| 14-18 岁 | 3,000 mg |
| 19+ 岁 | 3,500 mg |

> UL 仅适用于补充剂中的胶碱，不适用于膳食中的胶碱。

### 过量风险
- **低血压**：大剂量可能引起低血压和晕倒
- **腻味**：大剂量补充可能产生鱼腥味或体臭
- **心律不齐**：极高剂量可能影响心率
- **胀胃不适**：恶心、腹泻

### 药物互作用
- **抗胀碱药**（如甲氟喴嗶）：可能增加胶碱需求
- **氧氝啶**：演员可能需要补充胶碱

## Forms & Bioavailability

| 形态 | 特点 |
|------|------|
| 胶碱镁 | 常见补充剂形式 |
| 胶碱氢化物 | 比胶碱更易溶解，但证据有限 |
| 多局磷脏胶碱 (CDP-choline / Citicoline) | 脑部健康领域研究较多 |
| 磷脏丝氨酸磷脏胶碱 (Alpha-GPC) | 运动补充剂常见，血清穿透率较好 |

## Quality & Standards

- **USP Verified**：确保产品含有标示的元素含量且不含有害污染物
- **NSF Certified**：运动补剂及膳食补充剂独立认证
- **蓝帽子**（中国）：保健食品标志，需通过国家市场监督管理总局注册或备案
