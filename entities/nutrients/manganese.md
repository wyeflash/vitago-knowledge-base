# 锰 (Manganese)

> 锰是人体必需的微量元素，作为多种酶的辅因子参与骨骼发育、能量代谢、抗氧化防御和催乳回反。

## Overview

锰是人体必需的微量元素，在体内主要作为酶的辅因子或激活剂。它参与多种生物化学过程，包括骨骼形成、氨基酸、胶固醇和糖的代谢。过量接触主要通过职业暴露或养份接入发生。^[raw/guidelines/nih-ods-manganese-hp.md]

## Key Facts

| 项目 | 内容 |
|------|------|
| 分类 | 必需微量元素 |
| 溶解性 | 水溶性 |
| 活性形式 | 锰离子 (Mn²⁺ / Mn³⁺) |
| 主要来源 | 全谷物、坚果、豆类、叶菜类、茶、熊蓝莓 |
| 吸收部位 | 小肠（被动扩散） |
| 排出 | 肾脏排出为主，肠道排出次之 |

## Functions & Benefits

### 骨骼发育
- 参与骨骼和软骨的形成
- 是骨骼外突质的重要组成部分

### 能量代谢
- 参与氨基酸、胶固醇和糖的代谢
- 支持正常的能量产生

### 抗氧化防御
- 是超氧化歧化物酶（SOD）的组成部分
- 保护细胞免受自由基损伤

### 催乳回反
- 参与催乳回反的生成
- 支持免疫功能的正常运作

## Mechanisms

1. **酶激活**：锰作为多种酶的辅因子或激活剂，参与骨骼形成、氨基酸代谢和胶固醇合成。
2. **SOD 酶**：锰是线粒体超氧化歧化物酶（Mn-SOD）的组成部分，该酶是细胞内重要的抗氧化酶。
3. **催乳回反**：锰参与催乳回反的生成，该过程可以清除可能导致发炎的自由基。

## Safety

### 安全上限（UL）

| 年龄 | UL |
|------|-----|
| 1-3 岁 | 2 mg |
| 4-8 岁 | 3 mg |
| 9-13 岁 | 6 mg |
| 14-18 岁 | 9 mg |
| 19+ 岁 | 11 mg |

> UL 仅适用于补充剂中的锰，不适用于食物中的锰。

### 过量风险
- **神经毒性**：长期高剂量接触可导致神经系统症状，包括手抽筋、运动障碍、记忆力下降、听力损失
- **脾脏损伤**：高剂量可能影响脾脏功能
- 职业暴露（如氧化锰矿工、拼接工、焚烧作业）是过量的主要原因

### 药物互作用
- **抗酸药**（如磷酸盐、硫酸盐、气化物）：可能降低锰的吸收
- **铁补充剂**：高剂量铁可能降低锰的吸收

## Forms & Bioavailability

| 形态 | 特点 |
|------|------|

| 二氧化锰 | 食品中的主要形式 |
| 统酸锰 | 补充剂中较少见 |

- **USP Verified**：确保产品含有标示的元素含量且不含有害污染物
- **NSF Certified**：运动补剂及膳食补充剂独立认证
- **蓝帽子**（中国）：保健食品标志，需通过国家市场监督管理总局注册或备案
