# 实体概览

> 实体（Entity）是知识库中可以被独立识别和定义的具体对象。VitaGo KB 的实体主分类采用“成分本体优先”的科学分类原则：先按物质属性与来源归类，功效方向、适用场景和人群用途通过标签、概念页和指引页表达，避免同一实体在多个主类中重复出现。

## 分类原则

1. **营养素**：经典营养学中的宏量营养素、维生素、矿物质、脂肪酸等。
2. **植物与草本成分**：来源于植物、草本或其标准化提取物的补充剂成分。
3. **非必需活性成分**：不是经典必需营养素，但在补充剂行业中作为具有明确生理活性的成分使用。
4. **微生态与消化支持**：影响肠道菌群、益生元/益生菌/后生元或消化酶相关的实体。
5. **机构、数据库与认证**：监管机构、权威数据库、指南来源和第三方质量认证体系。
