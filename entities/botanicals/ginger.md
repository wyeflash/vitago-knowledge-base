# 姜

> Zingiber officinale 根茎，传统用于消化不适、恶心和炎症。现代研究对恶心（孕吐、化疗相关、术后）和痛经有最充分的支持证据。

## Overview

姜（Ginger, *Zingiber officinale*）是一种多年生草本植物，原产于亚洲温暖地区，现广泛种植于南美洲、非洲和中东。其根茎（地下茎）用于食品和保健目的。姜在民间医学中有悠久历史，传统用于哮喘、流感、消化不良和胃肠不适等。目前主要推广用于恶心和呕吐、骨关节炎、痛经和其他病症。

## Key Facts

| 项目 | 内容 |
|------|------|
| 植物学名 | *Zingiber officinale* Roscoe |
| 常用名 | Ginger, ginger root, sheng jiang (生姜) |
| 活性化合物 | 姜辣素（gingerols）、姜烯酚（shogaols）、姜酮（zingerone） |
| 主要用途 | 恶心与呕吐、痛经、骨关节炎、消化不良 |
| 常见剂型 | 鲜姜、干姜粉、提取物胶囊、姜茶、精油 |
| 典型剂量 | 姜粉 0.5–2 g/天；提取物 250–500 mg，每日 2–4 次 |

## Traditional Uses & Active Compounds

姜是中国、印度和阿拉伯医学体系中最古老的贸易香料和药物之一。中医将生姜（鲜姜）和干姜区分使用：生姜偏重于发散风寒、温中止呕；干姜偏重于温中散寒、回阳通脉。阿育吠陀医学中姜用于消化火（agni）的增强和炎症治疗。航海时代欧洲用姜预防晕船。

姜的辛辣味和药理活性主要来自**姜辣素**（gingerols），这是一系列酚酮类化合物，其中 6-姜辣素含量最丰富。干姜和加热处理后的姜含有更多**姜烯酚**（shogaols），由姜辣素脱水形成，辛辣味更强，某些研究表明其生物活性可能更强。姜还含有挥发油（倍半萜类）和姜酮（zingerone），后者具有抗氧化活性。

## Research Evidence

### 恶心与呕吐
- **晕动病**：大多数研究显示姜对预防晕动病效果有限或不一致。^[raw/guidelines/nccih-ginger.html]
- **孕吐**：多项系统评价认为姜可能对妊娠期恶心和呕吐有帮助，且食物用量通常安全。但建议孕妇在使用前咨询医生。^[raw/guidelines/nccih-ginger.html]
- **化疗相关恶心**：姜作为标准止吐治疗的附加疗法可能有帮助，但证据尚不确定。^[raw/guidelines/nccih-ginger.html]
- **术后恶心**：证据不确定。^[raw/guidelines/nccih-ginger.html]

### 痛经
多项研究显示姜粉在月经前 3 天开始服用，对原发性痛经的缓解效果与布洛芬等 NSAIDs 相当。^[raw/guidelines/nccih-ginger.html]

### 骨关节炎
姜膳食补充剂可能对膝关节骨关节炎症状有帮助，但许多研究质量较差。外用姜未被证明有效。^[raw/guidelines/nccih-ginger.html]

### 消化不良
传统用途获得一定现代研究支持，姜可促进胃排空、减少餐后腹胀感。

## Safety & Precautions

### 常见不良反应
- 腹部不适、烧心、腹泻
- 口腔和咽喉刺激（尤其高剂量或鲜姜）

### 安全性总体评价
姜在多数研究中口服使用是安全的。外用姜产品也相对安全。^[raw/guidelines/nccih-ginger.html]

### 注意事项
- **孕期**：食物用量安全；补充剂用量在多数研究中也安全，但仍建议咨询医生。
- **哺乳期**：安全性数据有限。
- **胆结石**：理论上姜促进胆汁分泌，胆道疾病患者应谨慎。

## Dosage & Forms

| 剂型 | 特点 |
|------|------|
| **鲜姜** | 传统形式，姜辣素含量高，适合烹饪和泡茶 |
| **干姜粉** | 传统中药形式，便于储存和使用 |
| **标准化提取物** | 标准化姜辣素含量（如 5%） |
| **姜茶** | 温和形式，适合日常饮用 |
| **精油（外用）** | 用于局部按摩，不可内服 |

## Drug Interactions

- **抗凝药/抗血小板药**（华法林、阿司匹林）：姜可能抑制血小板聚集，理论上增加出血风险，但食物用量通常安全。
- **降糖药**：姜可能降低血糖，与降糖药联用需监测。
- **降压药**：姜可能有轻度降压作用，与降压药联用需监测。
- **抗酸药/H2 受体拮抗剂**：姜可能刺激胃酸分泌，理论上可能减弱抗酸药效果。

## Special Populations

| 人群 | 建议 |
|------|------|
| 孕妇 | 食物用量安全；补充剂用量通常安全（≤1 g/天），建议咨询医生 |
| 哺乳期 | 数据有限，适量食用安全 |
| 胆道疾病 | 谨慎使用 |
| 出血性疾病/术前 | 术前 1–2 周停用高剂量补充剂 |
| 糖尿病患者 | 监测血糖 |
| 低血压患者 | 高剂量可能加重低血压 |
