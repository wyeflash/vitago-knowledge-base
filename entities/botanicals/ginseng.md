# 人参 / 西洋参

> Panax ginseng（亚洲人参）与 Panax quinquefolius（西洋参）是传统适应原草本，主要活性成分为人参皂苷（ginsenosides）。研究证据集中于疲劳、认知与血糖管理。

## Overview

人参（Ginseng）指五加科人参属（*Panax*）植物的根部，最常用的为亚洲人参（*Panax ginseng*，又称高丽参、中国人参）和西洋参（*Panax quinquefolius*，又称花旗参）。"红参"和"白参"指亚洲人参经不同加工方式制成的产品。在传统中医中，人参被用作镇静剂和适应原，用于帮助机体抵抗生理和心理压力。

## Key Facts

| 项目 | 内容 |
|------|------|
| 植物学名 | *Panax ginseng* (亚洲人参); *Panax quinquefolius* (西洋参) |
| 常用名 | Asian ginseng, Korean ginseng, American ginseng |
| 活性化合物 | 人参皂苷（ginsenosides / panaxosides） |
| 主要用途 | 疲劳、认知功能、压力、运动表现、血糖管理 |
| 常见剂型 | 根提取物、红参、白参、胶囊、茶 |
| 典型剂量 | 因制剂而异，提取物通常 200–400 mg/天 |

## Traditional Uses & Active Compounds

人参在远东地区（包括朝鲜半岛、中国东北和远东西伯利亚）已有数千年栽培和使用历史。传统中医将其用于增强元气、改善疲劳、提升认知和延年益寿。西洋参则原产于北美，传统上被原住民用于退热和止痛。

人参含有多种化学成分，其中最重要的是**人参皂苷**（ginsenosides 或 panaxosides），这是一类三萜皂苷。不同种类的人参和不同加工方式（红参 vs 白参）的人参皂苷谱不同，这可能导致其药理活性的差异。

## Research Evidence

### 疲劳
2023 年对 19 项研究（2,413 名参与者）的综述提示两个重要结果：亚洲人参单独使用可能对一般性疲劳有轻度益处；而含有人参的某些复方草本可能对慢性疲劳更有益，但人参单独使用的效果尚不一致。^[raw/guidelines/nccih-ginseng.html]

### 认知功能
少量研究表明，亚洲人参可能改善中年成人的认知功能（包括抽象思维、注意力、算术技能和反应时间），但对年轻人无明显效果。对记忆的好处似乎依赖于与银杏叶联用。^[raw/guidelines/nccih-ginseng.html]

### 糖尿病
有限证据提示人参皂苷可能对 2 型糖尿病患者的血糖控制有益，但需要更多大规模长期研究。^[raw/guidelines/nccih-ginseng.html]

### 其他用途
初步研究显示人参可能对预防流感风险有帮助，但对症状严重程度和持续时间无影响。对于运动表现、哮喘和焦虑，证据不足。^[raw/guidelines/nccih-ginseng.html]

## Safety & Precautions

### 常见不良反应
- 失眠（最常见的副作用）
- 严重皮疹、肝损伤（罕见）
- 严重过敏反应（罕见）
- 可能加重自身免疫性疾病
- 可能干扰血液凝固^[raw/guidelines/nccih-ginseng.html]

### 禁忌与警告
- **孕期**：口服亚洲人参在孕期可能不安全。动物研究发现某些化学成分可导致出生缺陷。
- **哺乳期**：安全性未知。
- **糖尿病患者**：人参可能降低血糖，使用降糖药者需监测血糖。

## Dosage & Forms

| 剂型 | 特点 |
|------|------|
| **白参** | 鲜人参干燥而成，保留较多天然人参皂苷 |
| **红参** | 经蒸煮后干燥，某些人参皂苷转化，可能活性更强 |
| **根提取物** | 标准化人参皂苷含量（通常 4–7%） |
| **西洋参** | 一般认为较亚洲人参更温和，更不易引起失眠 |

## Drug Interactions

- **抗凝药/抗血小板药**：可能增加出血风险。
- **降糖药**：可能增强降糖效果，导致低血糖。
- **免疫抑制剂**：可能刺激免疫系统，减弱免疫抑制药物效果。
- **中枢神经系统兴奋剂**：可能与咖啡因等产生叠加效应，加重失眠。
- **抗抑郁药（MAOI）**：传统上认为应避免联用。

## Special Populations

| 人群 | 建议 |
|------|------|
| 孕妇 | 避免使用 |
| 哺乳期 | 安全性未知，避免使用 |
| 自身免疫病患者 | 可能加重病情，避免使用 |
| 糖尿病患者 | 需监测血糖 |
| 术前患者 | 术前 1–2 周停用，因其可能影响凝血 |
