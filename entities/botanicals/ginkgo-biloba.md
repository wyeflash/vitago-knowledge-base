# 银杏叶

> Ginkgo biloba 被称为"活化石"，是最古老的植物物种之一。叶提取物被广泛用于认知健康和循环系统支持，但高质量证据未能证实其对痴呆的预防作用。

## Overview

银杏（*Ginkgo biloba*）是一种落叶乔木，是银杏科银杏属的唯一现存物种，被誉为"活化石"。其叶提取物是最常用的补充形式，标准化含有 24% 黄酮苷和 6% 萜内酯。传统中医使用银杏叶和种子治疗咳嗽、腹泻和其他疾病。现代补充剂主要推广用于焦虑、心脏病、认知障碍与痴呆、糖尿病、经前期综合征和精神分裂症等。

## Key Facts

| 项目 | 内容 |
|------|------|
| 植物学名 | *Ginkgo biloba* L. |
| 常用名 | Ginkgo, maidenhair tree, fossil tree |
| 活性化合物 | 黄酮苷（flavonoids）、萜内酯（terpenoids，包括银杏内酯和白果内酯） |
| 主要用途 | 认知功能、痴呆、焦虑、耳鸣、循环健康 |
| 常见剂型 | 叶提取物（标准化 EGb761）、胶囊、片剂 |
| 典型剂量 | 120–240 mg/天，分 2–3 次服用 |

## Traditional Uses & Active Compounds

银杏在中国医学中有悠久的使用历史。叶和种子均被入药，传统用于治疗咳嗽、哮喘、腹泻、尿频等。需要注意的是，**生银杏种子有毒**，含银杏毒素（ginkgotoxin），可引起惊厥，不可生食。

银杏叶提取物含有两类主要活性成分：**黄酮苷**（具有抗氧化活性）和**萜内酯**（包括银杏内酯——血小板活化因子拮抗剂，和白果内酯——改善微循环）。标准化提取物 EGb761 含有 24% 黄酮苷和 6% 萜内酯。

## Research Evidence

### 痴呆与认知功能
**无证据支持预防痴呆。** 三项在认知功能正常或轻度认知障碍老年人中进行的大型研究（包括 NIH 资助的 Ginkgo Evaluation of Memory, GEM 研究，>3,000 名 75 岁以上参与者，中位随访 6 年）均未发现银杏提取物能降低痴呆或阿尔茨海默病的发生风险。^[raw/guidelines/nccih-ginkgo.html]

银杏提取物可能对痴呆症状有轻度益处（尤其是较高剂量），但证据不一致。对于轻度认知障碍的效果尚不明确。

### 其他宣称用途
尽管银杏被推广用于焦虑、心脏病、糖尿病、耳鸣、PMS 和精神分裂症等多种疾病，但**目前没有确凿证据表明银杏对任何健康状况有效**。^[raw/guidelines/nccih-ginkgo.html]

## Safety & Precautions

### 常见不良反应
- 头痛、头晕、心悸、便秘、胃肠不适
- 过敏反应（对银杏果过敏者可能对叶提取物也敏感）

### 禁忌与警告
- **出血风险**：银杏可能抑制血小板活化因子（PAF），增加出血风险。术前应停用。
- **癫痫**：银杏种子中的银杏毒素可降低癫痫阈值，叶提取物也应谨慎使用。
- **孕期/哺乳期**：安全性数据不足。

## Dosage & Forms

| 剂型 | 特点 |
|------|------|
| **标准化叶提取物 EGb761** | 研究最充分的制剂，24% 黄酮苷 + 6% 萜内酯 |
| **普通叶提取物** | 标准化程度不一 |
| **胶囊/片剂** | 常见口服形式 |

## Drug Interactions

- **抗凝药/抗血小板药**（华法林、阿司匹林、氯吡格雷）：可能增加出血风险，是最重要的药物相互作用。
- **NSAIDs**（布洛芬等）：可能增加胃肠道出血风险。
- **抗癫痫药**：理论上可能降低癫痫阈值。
- **抗抑郁药**：个别报告可能与 SSRIs 相互作用。

## Special Populations

| 人群 | 建议 |
|------|------|
| 孕妇/哺乳期 | 避免使用（数据不足） |
| 术前患者 | 术前 1–2 周停用 |
| 出血性疾病患者 | 避免使用 |
| 癫痫患者 | 谨慎使用 |
| 服用抗凝药者 | 避免使用或严格监测 |
