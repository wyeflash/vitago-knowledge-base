# 姜黄素

> 姜黄（Curcuma longa）根茎中的主要活性成分，属姜黄素类（curcuminoids）。传统用于消化和炎症，现代研究集中于骨关节炎和代谢健康，但口服生物利用度极低。

## Overview

姜黄素（Curcumin）是姜黄（*Curcuma longa*）根茎中的主要活性成分，赋予姜黄黄色。姜黄属于姜科，原产于东南亚和印度，其根茎数千年来用于烹饪和传统医学（阿育吠陀、中医、伊斯兰医学和泰医）。传统用途包括消化不良、感冒、皮肤感染、关节炎、腹痛和肝病。现代口服姜黄素被推广用于骨关节炎、抑郁、过敏、瘙痒和高胆固醇等；外用姜黄素用于骨关节炎皮肤症状。

## Key Facts

| 项目 | 内容 |
|------|------|
| 来源植物 | *Curcuma longa* L. (姜黄) |
| 常用名 | Curcumin, turmeric extract, turmeric |
| 活性化合物 | 姜黄素类（curcuminoids）：姜黄素、去甲氧基姜黄素、双去甲氧基姜黄素 |
| 主要用途 | 骨关节炎、炎症、抗氧化、消化不良 |
| 常见剂型 | 姜黄素提取物、磷脂复合物（Meriva）、纳米颗粒、与胡椒碱联用 |
| 典型剂量 | 500–2,000 mg/天姜黄素（取决于制剂和生物利用度增强技术） |

## Traditional Uses & Active Compounds

姜黄在印度、中国和东南亚传统医学中有数千年历史。在阿育吠陀中被称为"黄金香料"，用于净化血液、治疗皮肤病、消化问题和关节炎症。在印度教仪式中也有宗教用途。咖喱的黄色即来自姜黄。传统上，姜黄常与黑胡椒同用，现代研究证实胡椒碱（piperine）可显著提高姜黄素生物利用度。

姜黄素类是一组多酚化合物，其中**姜黄素**（curcumin）占姜黄根茎干重的 2–8%。去甲氧基姜黄素和双去甲氧基姜黄素是另外两种主要姜黄素类。姜黄素具有强抗氧化和抗炎活性，能抑制 NF-κB、COX-2、LOX 和诱导型一氧化氮合酶（iNOS）等炎症介质。然而，其**口服生物利用度极低**（<1%），因快速被肝脏和肠道代谢，且水溶性差。

## Research Evidence

### 骨关节炎
多项 Meta 分析评估了口服姜黄素/姜黄对骨关节炎的效果。初步证据是积极的：姜黄素可能有助于缓解膝关节疼痛和僵硬、改善关节功能。但证据质量参差不齐，需要更高质量的研究来得出确定性结论。^[raw/guidelines/nccih-turmeric.html]

### 非酒精性脂肪肝病（NAFLD）
多项研究评估了姜黄素/姜黄对 NAFLD 的效果，但结果不一致，不足以得出确定性结论。^[raw/guidelines/nccih-turmeric.html]

### 高胆固醇/血脂异常
部分研究显示姜黄素可能对血脂谱有轻度改善作用，但证据尚不充分。^[raw/guidelines/nccih-turmeric.html]

### 其他用途
对于抑郁、过敏、瘙痒、癌症预防等，目前证据不足。^[raw/guidelines/nccih-turmeric.html]

## Safety & Precautions

### 常见不良反应
- 高剂量可能引起恶心、腹泻和消化不良
- 皮肤接触姜黄可能引起过敏或染色

### 肝毒性警告
**高生物利用度姜黄素制剂（如纳米姜黄素、磷脂复合物、含胡椒碱配方）可能与肝损伤相关。** 多个监管机构已对此发出警告。2023 年以来，FDA 和 EFSA 均报告了与高度生物可利用姜黄素产品相关的肝损伤案例。^[raw/guidelines/nccih-turmeric.html]

### 其他注意事项
- 姜黄可能刺激胆囊收缩，胆道梗阻或胆结石患者应避免。
- 高剂量可能影响铁吸收。

## Dosage & Forms

| 剂型 | 特点 | 生物利用度增强 |
|------|------|----------------|
| **普通姜黄素粉** | 成本最低 | 极低（<1%） |
| **姜黄素 + 胡椒碱** | 添加黑胡椒提取物 | 提高约 20 倍 |
| **磷脂复合物（Meriva）** | 与磷脂结合 | 提高约 29 倍 |
| **纳米颗粒姜黄素** | 纳米技术制备 | 显著提高，但肝毒性风险需关注 |
| **脂质体姜黄素** | 包裹在脂质体中 | 显著提高 |
| **水溶性姜黄素** | 化学修饰增加水溶性 | 显著提高 |

> 比较不同产品的证据质量时较困难，因口服姜黄素产品实际含量差异大，且常含有其他植物成分。

## Drug Interactions

- **抗凝药/抗血小板药**：姜黄/姜黄素可能抑制血小板聚集，增加出血风险。
- **降糖药**：可能增强降糖效果，需监测血糖。
- **铁补充剂**：高剂量姜黄素可能抑制铁吸收。
- **化疗药物**：高剂量可能干扰某些化疗药，肿瘤患者应在医生指导下使用。

## Special Populations

| 人群 | 建议 |
|------|------|
| 孕妇/哺乳期 | 食物用量安全；补充剂数据不足，避免高剂量 |
| 胆道疾病/胆结石 | 姜黄刺激胆囊收缩，避免使用 |
| 出血性疾病/术前 | 术前 1–2 周停用 |
| 肝病患者 | 避免高生物利用度制剂 |
| 铁缺乏者 | 与铁剂间隔服用 |
| 激素敏感性疾病 | 理论上姜黄有弱雌激素活性，敏感者谨慎 |
