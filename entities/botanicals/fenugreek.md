# 葫芦巴

> *Trigonella foenum-graecum*，原产于地中海地区的雏形科草本。其种子气味与口感类似枫糖，已有约 6,000 年药用历史。现代主要用于血糖调控与母乳分泌支持。^[raw/guidelines/nccih-fenugreek.html]

## Overview

葫芦巴（Fenugreek, *Trigonella foenum-graecum*）是一种雏形科草本，原产于地中海地区、南欧和西亚。其种子被用作香料、传统药物和食品调味剂。在传统医学中，葫芦巴被用作滋补剂、滞药，用于月经痛、更年期症状、肾结石等，并用于促进哺乳期乳汁分泌。

## Key Facts

| 项目 | 内容 |
|------|------|
| 植物学名 | *Trigonella foenum-graecum* L. |
| 常用名 | Fenugreek, Greek hay, methi |
| 活性化合物 | 葫芦巴碱、纤维、粘胶、4-羏烯要醇 |
| 主要用途 | 血糖控制、哺乳、月经痛 |
| 常见剂型 | 种子粉、胶囊、提取物 |
| 典型剂量 | 种子粉 5–30 g/日；提取物 500–600 mg/日 |

## Research Evidence

### 2 型糖尿病与血糖控制
研究提示葫芦巴可能有助于降低 2 型糖尿病患者的血糖水平，但许多研究质量不高。证据整体较弱，需更多高质量研究。^[raw/guidelines/nccih-fenugreek.html]

### 哺乳期乳汁分泌
少数研究评估了葫芦巴对哺乳期女性乳汁产量的影响，结果混杂。目前尚不确定葫芦巴是否能有效增加乳汁产量。^[raw/guidelines/nccih-fenugreek.html]

### 月经痛
只有少量研究检查了葫芦巴对月经痛的影响，证据质量低，效果不确定。

## Safety & Precautions

### 重要安全警告
- **孕期：禁用大于食用量的葫芦巴**，因其使用与出生缺陷风险增加相关（动物和人类数据均有报告）。

### 常见不良反应
- 腹泻、恶心、消化道不适
- 大剂量可能导致血糖过低
- 过敏反应（包括严重反应）

### 注意事项
- **哺乳期**：大于食用量的安全性数据不足，建议谨慎。
- **血糖监测**：如正在服用降糖药，合用可能导致低血糖。
- **凝血功能**：葫芦巴可能影响凝血，手术前应告知医生。

## Drug Interactions

- **降糖药**：可能增强降血糖效果，监测血糖。
- **抗凝血药**：可能影响凝血功能。
- **布洛芬**：可能增加出血风险。
- **铁剂**：葫芦巴中的纤维可能降低铁吸收。

## Special Populations

| 人群 | 建议 |
|------|------|
| 孕妇 | 禁用大于食用量的葫芦巴 |
| 哺乳期女性 | 安全性数据不足，谨慎使用 |
| 糖尿病患者 | 合用降糖药时需监测血糖 |
| 出血性疾病患者 | 谨慎，可能影响凝血 |

## Practical Use Notes

草本成分更适合做“是否值得尝试、是否存在相互作用、是否需要避开”的风险分层，而不是做精确剂量处方。开始使用前建议先确认目标症状是否已有明确诊断，避免把贫血、甲状腺疾病、感染、肿瘤、严重焦虑抑郁或药物不良反应误当作普通疲劳、睡眠差或消化不适。若试用，通常应一次只引入一种新成分，记录剂量、品牌、批号、开始日期、目标指标和不良反应；4–8 周无明确收益时应停止，而不是持续叠加更多草本产品。

对于慢病患者，草本补充剂的最大风险往往不是“无效”，而是延误正规治疗或与处方药叠加。正在使用抗凝/抗血小板药、降压药、降糖药、抗抑郁药、镇静催眠药、免疫抑制剂、激素治疗、抗癫痫药或肿瘤治疗药物者，应把草本产品纳入用药清单，与医生或药师共同评估。
