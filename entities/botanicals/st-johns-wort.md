# 圣约翰草

> Hypericum perforatum，传统上用于抑郁、伤口愈合和感冒。现代研究证实其对轻中度抑郁有效，但以严重的药物相互作用著称，与多种处方药存在危险互作。

## Overview

圣约翰草（St. John's Wort, *Hypericum perforatum*）是一种开黄色花的植物，在希腊医学、伊斯兰医学和中医等传统医学体系中广泛使用。名称源自施洗者圣约翰，因其花期在 6 月下旬圣约翰节前后。传统用途包括治疗抑郁、胃溃疡、感冒和促进伤口愈合。目前最广泛推广用于抑郁症状，也用于更年期症状和其他病症。外用制剂用于伤口和皮肤疾病。

## Key Facts

| 项目 | 内容 |
|------|------|
| 植物学名 | *Hypericum perforatum* L. |
| 常用名 | St. John's wort, hypericum, goatweed |
| 活性化合物 | 金丝桃素（hypericin）、金丝桃素（hyperforin）、黄酮类 |
| 主要用途 | 轻中度抑郁、更年期潮热、躯体症状障碍、伤口愈合（外用） |
| 常见剂型 | 胶囊、片剂、茶、酊剂、外用油/软膏 |
| 典型剂量 | 300 mg（标准化 0.3% 金丝桃素），每日 2–3 次 |

## Traditional Uses & Active Compounds

圣约翰草在欧洲传统医学中有悠久历史，用于治疗精神疾病、神经痛、创伤、烧伤和虫咬。其使用可追溯至古希腊，希波克拉底和迪奥斯科里德斯均有记载。传统上也被认为可以驱邪。

圣约翰草含有多种生物活性成分，包括**金丝桃素**（hypericin）、**金丝桃素**（hyperforin，去甲肾上腺素-多巴胺-5-HT 再摄取抑制剂）、黄酮类化合物和原花青素。金丝桃素被认为与光敏反应相关，而金丝桃素是其抗抑郁活性的关键成分。

## Research Evidence

### 抑郁
多项研究表明，圣约翰草对**轻中度抑郁**可能比安慰剂更有效，且与标准抗抑郁药物效果相当。然而，对于**重度抑郁**的效果尚不确定，且研究持续时间通常不超过 12 周。^[raw/guidelines/nccih-stjohnswort.html]

### 更年期
少数研究表明，圣约翰草可能对更年期相关潮热有帮助。^[raw/guidelines/nccih-stjohnswort.html]

### 其他用途
对于躯体症状障碍（一种以对躯体症状极度焦虑为特征的疾病），有少量证据提示可能有益。对于 ADHD、肠易激综合征、强迫症、经前期综合征、戒烟和伤口愈合等，证据不足。^[raw/guidelines/nccih-stjohnswort.html]

## Safety & Precautions

### 常见不良反应
- 光敏反应（皮肤对阳光敏感），尤其高剂量时
- 焦虑、口干、头晕、胃肠不适、疲劳、头痛、性功能障碍

### 严重警告
**圣约翰草可与多种药物产生危险甚至危及生命的相互作用。** 它通过诱导 CYP3A4、CYP2C9、CYP1A2 和 P-糖蛋白（P-gp）加速多种药物的代谢，导致药效降低。^[raw/guidelines/nccih-stjohnswort.html]

### 禁忌
- **与其他抗抑郁药联用**：可能导致 5-羟色胺综合征。
- **避孕药**：可能降低口服避孕药效果，导致意外怀孕。
- **抗凝药**（华法林）：可能降低抗凝效果，增加血栓风险。
- **免疫抑制剂**（环孢素、他克莫司）：可能降低血药浓度，导致移植排斥。
- **抗逆转录病毒药物**（HIV 治疗）：可能降低抗病毒效果。
- **抗癫痫药、强心苷、某些抗癌药**：均可能受影响。
- **光敏性疾病患者**：应避免使用。

## Dosage & Forms

| 剂型 | 特点 |
|------|------|
| **标准化提取物** | 通常标准化为 0.3% 金丝桃素或 2–5% 金丝桃素 |
| **胶囊/片剂** | 最常见口服形式 |
| **茶** | 传统使用形式，但活性成分含量不稳定 |
| **酊剂** | 酒精提取物 |
| **外用油/软膏** | 用于伤口愈合和轻度烧伤 |

## Drug Interactions

圣约翰草的药物相互作用范围极广，是其临床应用的最大限制因素：

- **抗抑郁药**（SSRIs、SNRIs、MAOIs、三环类）：5-HT 综合征风险
- **口服避孕药**：降低避孕效果
- **华法林**：降低抗凝效果
- **免疫抑制剂**（环孢素、他克莫司）：降低血药浓度
- **抗 HIV 药物**（蛋白酶抑制剂、NNRTIs）：降低抗病毒效果
- **抗癫痫药**（卡马西平、苯妥英）：降低抗癫痫效果
- **地高辛**：降低强心苷血药浓度
- **他汀类药物**：降低降脂效果
- **某些化疗药物**：降低抗癌效果

**服用任何处方药者，在使用圣约翰草前必须咨询医疗提供者。**

## Special Populations

| 人群 | 建议 |
|------|------|
| 孕妇/哺乳期 | 避免使用（安全性数据不足） |
| 重度抑郁患者 | 效果不确定，不建议替代标准治疗 |
| 服用处方药者 | 必须咨询医生，相互作用风险极高 |
| 光敏性疾病患者 | 避免使用 |
| 准备手术者 | 术前停用 |
| 双相情感障碍 | 可能诱发躁狂，避免使用 |
