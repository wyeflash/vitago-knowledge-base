# 乳酸杆菌属

> 革兰氏阳性、不产孢子的兼性厌氧或微需氧杆菌，是发酵食品和人类共生菌群中最具代表性的益生菌属之一。不同菌种/菌株的功能差异显著，临床应用需区分到株水平。

## Overview

乳酸杆菌属（Lactobacillus sensu lato）是一大类形态、代谢和生态位多样的细菌。2020 年基于全基因组测序的分类学修订将其拆分为多个属，包括 *Lactobacillus* sensu stricto、*Lacticaseibacillus*、*Lactiplantibacillus*、*Limosilactobacillus*、*Ligilactobacillus* 等。日常和工业语境中仍常统称为"乳酸杆菌"或"乳杆菌"。

它们是乳制品发酵（酸奶、奶酪、开菲尔）和传统发酵蔬菜（泡菜、酸菜）的核心菌群，也是口腔、肠道和女性泌尿生殖道正常菌群的组成部分。

## Key Facts

| 项目 | 内容 |
|------|------|
| 分类地位 | 厚壁菌门 (Firmicutes)，乳杆菌目 (Lactobacillales) |
| 代谢特征 | 兼性厌氧/微需氧，发酵糖类产乳酸为主 |
| 主要栖息地 | 肠道、阴道、口腔、发酵食品 |
| 常见菌种 | *L. rhamnosus* GG、*L. acidophilus*、*L. reuteri*、*L. casei*、*L. plantarum* |
| 常见剂型 | 冻干胶囊/片剂、酸奶、开菲尔、发酵乳饮料 |
| 典型剂量 | 10⁸–10¹⁰ CFU/天，依菌株和适应症而异 |

## Research Evidence

### 抗生素相关性腹泻 (AAD)
多项系统评价和 Meta 分析显示，特定乳酸杆菌菌株（尤其是 *L. rhamnosus* GG 和 *L. casei*）可降低成人和儿童抗生素相关性腹泻风险。效果具有菌株依赖性，非所有乳酸杆菌均有效。

### 急性感染性腹泻
对儿童急性腹泻，某些乳酸杆菌菌株可缩短腹泻持续时间约 1 天。证据最充分的是 *L. rhamnosus* GG。成人证据较弱。

### 肠易激综合征 (IBS)
部分菌株（如 *L. plantarum* 299v）对缓解 IBS 腹胀、腹痛有一定证据，但结果不一致，可能与菌株选择和 IBS 亚型有关。

### 阴道健康
口服或阴道用乳酸杆菌（如 *L. rhamnosus* GR-1、*L. reuteri* RC-14）在预防细菌性阴道病和念珠菌性阴道炎复发方面有一定研究支持。

### 幽门螺杆菌辅助根除
作为标准三联/四联疗法的辅助，某些乳酸杆菌菌株可提高根除率并减轻治疗相关胃肠道副作用。

### 免疫调节
部分菌株可刺激肠道相关淋巴组织 (GALT)，调节 sIgA 分泌和细胞因子平衡，但临床免疫终点证据仍有限。

## Mechanisms

| 机制 | 说明 |
|------|------|
| 产酸竞争 | 产生乳酸和乙酸，降低局部 pH，抑制病原菌生长 |
| 过渡效应 | 与肠上皮和阴道上皮黏附，竞争性排除病原体 |
| 细菌素分泌 | 部分菌株产生细菌素 (bacteriocins)，直接抑制竞争菌 |
| 增强屏障 | 促进紧密连接蛋白表达，增强肠上皮屏障功能 |
| 免疫调节 | 通过树突状细胞和巨噬细胞上的模式识别受体 (PRR) 调节免疫应答 |
| 代谢互作 | 参与胆汁酸代谢、短链脂肪酸前体生成 |

## Populations & Dosage

| 人群/用途 | 菌株示例 | 典型剂量 | 证据等级 |
|-----------|----------|----------|----------|
| 抗生素相关性腹泻预防 | *L. rhamnosus* GG | 10¹⁰ CFU/天 | 中等 |
| 儿童急性腹泻 | *L. rhamnosus* GG | 10¹⁰ CFU/天 | 中等 |
| IBS 腹胀/腹痛 | *L. plantarum* 299v | 10¹⁰ CFU/天 | 低-中等 |
| 阴道健康维护 | *L. rhamnosus* GR-1 + *L. reuteri* RC-14 | 10⁹ CFU/天 | 低-中等 |
| H. pylori 辅助根除 | 多种乳酸杆菌菌株 | 10⁹–10¹⁰ CFU/天 | 低-中等 |

## Safety

### 常见不良反应
- 腹胀、胀气（尤其起始 1–2 周）
- 腹部不适、轻度腹泻

### 安全性总体评价
乳酸杆菌在健康人群中通常安全。乳酸菌血症极其罕见，多发生于重症住院患者或有中心静脉导管者。

### 禁忌与注意事项
- **免疫功能严重低下者**（如化疗中性粒细胞减少、器官移植后）：理论上存在菌血症风险，需谨慎。
- **中心静脉导管患者**：避免口服益生菌。
- **急性胰腺炎**：部分指南建议避免使用。
- **心瓣膜疾病/人工瓣膜**：长期高剂量使用需咨询医生。

## Forms & Quality

| 剂型 | 特点 |
|------|------|
| **冻干胶囊/片剂** | 最常见，需关注活菌数和保质期 |
| **常温稳定型** | 采用微囊化或冻干保护技术，无需冷藏 |
| **发酵乳制品** | 传统载体，同时提供营养；活菌数波动较大 |
| **包埋技术** | 耐胃酸包埋可提高到达肠道的活菌比例 |

### 选购要点
- **菌株标识**：优质产品会明确标注菌种和菌株号（如 *L. rhamnosus* GG = ATCC 53103）
- **活菌数 (CFU)**：标注保质期末的最低活菌数，非生产时活菌数
- **储存条件**：部分产品需 2–8°C 冷藏，部分常温稳定
