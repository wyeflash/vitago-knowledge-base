# 布拉氏酵母菌

> 一种非致病性热带酵母菌，是目前研究证据最强的益生菌微生物之一，尤其在抗生素相关性腹泻和艰难梭菌感染预防方面有突出表现。属于真菌而非细菌，因此不受抗生素影响。

## Overview

布拉氏酵母菌（*Saccharomyces boulardii*，现多归类为 *Saccharomyces cerevisiae* var. *boulardii*）是由法国微生物学家 Henri Boulard 于 1923 年从荔枝和山竹果皮中分离出的热带酵母菌株。它与酿酒酵母 (*S. cerevisiae*) 亲缘关系密切，但具有独特的生理和药理特性。

作为唯一的酵母来源益生菌，其核心优势在于：**它是真核真菌，细菌靶向的抗生素不会将其杀灭**，因此可在抗生素治疗期间持续存活并发挥作用。

## Key Facts

| 项目 | 内容 |
|------|------|
| 分类地位 | 子囊菌门 (Ascomycota)，酵母属 (Saccharomyces) |
| 细胞类型 | 单细胞真核生物（酵母），非细菌 |
| 最适温度 | 37°C，适应哺乳动物肠道环境 |
| 常见菌株 | CNCM I-745（法国 Biocodex，研究最充分） |
| 常见剂型 | 冻干胶囊、散剂 |
| 典型剂量 | 250–500 mg/天（约 5×10⁹–10¹⁰ CFU）；急性期可增至 1000 mg/天 |

## Research Evidence

### 抗生素相关性腹泻 (AAD)
多项高质量 Meta 分析一致表明，布拉氏酵母菌可显著降低成人和儿童 AAD 风险，是 AAD 预防领域证据最强的单一益生菌。典型剂量为 250–500 mg/天，与抗生素同时使用。

### 艰难梭菌感染 (C. difficile) 预防与复发
- **初级预防**：与抗生素联用可降低艰难梭菌相关性腹泻 (CDAD) 发生率。
- **复发预防**：对艰难梭菌感染复发预防有明确效果，多次复发者中可作为辅助治疗。美国胃肠病学会 (ACG) 指南对此有有条件推荐。

### 急性腹泻（儿童与成人）
对儿童和成人的急性感染性腹泻有一定缩短病程作用，证据强度中等，尤其在儿童中研究较多。

### 旅行者腹泻
部分研究显示对预防旅行者腹泻有一定效果，但证据不如 AAD 充分。

### 幽门螺杆菌根除辅助
与乳酸杆菌类似，可作为标准根除方案的辅助，提高依从性和减轻副作用。

### 炎症性肠病 (IBD)
对溃疡性结肠炎维持缓解期可能有辅助作用，但克罗恩病证据不足。目前仅作为辅助手段，不能替代标准治疗。

## Mechanisms

| 机制 | 说明 |
|------|------|
| 抗毒素作用 | 分泌 54 kDa 蛋白酶，降解艰难梭菌毒素 A 和 B、霍乱毒素 |
| 抗菌肽分泌 | 产生可抑制病原菌的肽类物质 |
| 抗炎信号 | 调节 NF-κB 通路和促炎细胞因子（IL-8、TNF-α）产生 |
| 免疫调节 | 增强肠道 sIgA 分泌，激活树突状细胞 |
| 过渡竞争 | 与病原菌竞争肠上皮黏附位点和营养 |
| 抗真菌特性 | 抑制白色念珠菌等真菌过度生长 |

## Populations & Dosage

| 人群/用途 | 典型剂量 | 疗程 | 证据等级 |
|-----------|----------|------|----------|
| 成人 AAD 预防 | 250–500 mg/天 | 与抗生素同期 | 高 |
| 儿童 AAD 预防 | 250 mg/天 | 与抗生素同期 | 高 |
| 艰难梭菌复发预防 | 500 mg–1 g/天 | 4 周 | 中等 |
| 急性腹泻（儿童） | 250–500 mg/天 | 5–7 天 | 中等 |
| 旅行者腹泻预防 | 250–500 mg/天 | 旅行期间 | 低-中等 |
| H. pylori 辅助根除 | 500 mg/天 | 2 周 | 低-中等 |

## Safety

### 常见不良反应
- 腹胀、排气、轻度便秘或腹泻
- 口渴感（散剂口服时）

### 安全性总体评价
布拉氏酵母菌对一般人群安全。由于它是真菌，**理论上不存在细菌益生菌的菌血症风险**（但仍有个案报道真菌血症，极其罕见）。

### 重要注意事项
- **中心静脉导管患者**：**禁用**。有导管相关真菌血症报道，酵母菌可通过肠道移位入血并定植于导管。
- **免疫严重抑制患者**：需谨慎，虽无广泛禁忌，但重症患者应咨询医生。
- **酵母过敏者**：对啤酒酵母或面包酵母过敏者应避免。
- **抗真菌药物联用**：氟康唑等抗真菌药会杀死布拉氏酵母菌，需间隔使用（如可能）。

## Forms & Quality

| 剂型 | 特点 |
|------|------|
| **冻干胶囊** | 最常见，需阴凉干燥保存 |
| **散剂/颗粒** | 可溶于水或食物，适合吞咽困难者 |
| **常温稳定** | 多数产品无需冷藏，但避免高温高湿 |

### 选购要点
- 认准有研究支持的菌株（如 CNCM I-745）
- 关注每份 CFU 或毫克数标注
- 酵母益生菌不需冷藏，但避免 25°C 以上长期存放
