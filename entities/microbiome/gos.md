# 低聚半乳糖

> 由半乳糖单元通过 β-(1→4)、β-(1→6) 等糖苷键连接而成的短链寡糖，是母乳中天然存在的重要低聚糖结构类似物。作为选择性最强的益生元之一，对婴儿双歧杆菌的增殖作用尤为突出，是婴幼儿配方食品的核心益生元配料。

## Overview

低聚半乳糖（Galactooligosaccharides, GOS）是由乳糖通过 β-半乳糖苷酶转糖基作用合成的寡糖混合物，聚合度通常为 2–8，以三糖至五糖为主。其糖苷键类型（β-1,4、β-1,6 等）与母乳低聚糖 (HMOs) 中的结构类似，这是其在婴儿营养中具有特殊地位的原因。

母乳中含有超过 200 种低聚糖，是母乳中第三大固体成分，对婴儿肠道菌群定植和免疫发育至关重要。GOS（常与 FOS 复配）是婴幼儿配方中最接近模拟 HMO 功能的商业化益生元。

## Key Facts

| 项目 | 内容 |
|------|------|
| 化学类别 | 半乳糖寡糖，可溶性膳食纤维 |
| 聚合度 (DP) | 2–8（主要为三糖至五糖） |
| 甜度 | 约为蔗糖的 20–40% |
| 生产方式 | 乳糖酶法转糖基化 |
| 能量值 | 约 1.5–2.0 kcal/g |
| 常见剂型 | 粉剂、糖浆、婴幼儿配方添加 |
| 典型剂量 | 成人 3–10 g/天；婴幼儿配方 0.4–0.8 g/100 mL |

## Research Evidence

### 婴儿肠道菌群与配方奶
- GOS（尤其 GOS/FOS 复配，比例 9:1 或 4:1）是研究最充分的婴幼儿益生元组合。
- 可使配方奶喂养婴儿的粪便双歧杆菌比例、短链脂肪酸水平和粪便性状更接近母乳喂养婴儿。
- 对婴儿腹泻、便秘和过敏风险的潜在益处有一定研究支持，但证据强度中等。

### 免疫发育与过敏预防
部分研究显示，添加 GOS/FOS 的配方奶可能降低婴儿特应性皮炎和过敏性疾病风险，可能与肠道菌群调节和免疫耐受建立有关。但结果不一致，不能作为确定性结论。

### 成人肠道健康
成人研究中，GOS 同样可选择性促进双歧杆菌增殖，效果与 FOS 和菊粉类似。对成人便秘和肠功能的改善有中等强度证据。

### 矿物质吸收
GOS 可促进钙、镁和铁的吸收，机制与降低肠腔 pH 和增加矿物质溶解度有关。

### 肠屏障与病原体抵抗
GOS 可作为"诱饵受体"，与肠道病原菌的黏附素竞争性结合，减少病原菌对肠上皮的黏附。此机制在婴儿和动物模型中有较多研究。

## Mechanisms

| 机制 | 说明 |
|------|------|
| 选择性增殖 | 双歧杆菌（尤其 *B. infantis*）优先利用 GOS，竞争优势强 |
| HMO 模拟 | 结构类似母乳低聚糖，在婴儿肠道生态中发挥类似功能 |
| 产酸发酵 | 快速发酵产乙酸、乳酸，酸化肠腔 |
| 抗黏附 | 作为可溶性诱饵，竞争性抑制病原菌黏附肠上皮 |
| 免疫调节 | 促进 sIgA 分泌，调节 Th1/Th2 平衡 |
| 矿物质吸收 | 降低肠腔 pH，增加钙、镁、铁的溶解度和吸收 |

## Populations & Dosage

| 人群/用途 | 剂量 | 说明 | 证据等级 |
|-----------|------|------|----------|
| 婴幼儿配方 | 0.4–0.8 g/100 mL | 通常与 FOS 9:1 复配 | 中等 |
| 成人肠道健康 | 3–5 g/天起始 | 可增至 5–10 g/天 | 中等 |
| 便秘 | 5 g/天 | 分次随餐 | 低-中等 |
| 钙吸收促进 | 5–8 g/天 | 青少年和成人 | 低-中等 |

## Safety

### 常见不良反应
- 腹胀、胀气（起始期常见，通常 1–2 周适应）
- 腹部不适、肠鸣
- 软便或轻度腹泻（高剂量时）

### 安全性总体评价
GOS 安全性高，FDA 认定为 GRAS。在婴幼儿配方中的长期广泛使用积累了大量安全性数据。乳糖来源的 GOS 对乳糖不耐受者通常也安全，因为 GOS 的糖苷键不同于乳糖，不被乳糖酶水解。

### 注意事项
- **乳糖过敏（非乳糖不耐受）**：对牛奶蛋白过敏者，需确认 GOS 产品的乳糖残留量极低；GOS 本身不含牛奶蛋白。
- **IBS**：发酵性寡糖属 FODMAPs，部分 IBS 患者可能不耐受。
- **SIBO**：活跃期慎用。

## Forms & Quality

| 剂型 | 特点 |
|------|------|
| **GOS 粉剂** | 常见原料形式，微甜 |
| **GOS 糖浆** | 液体形式，用于食品和饮料 |
| **婴幼儿配方** | 与 FOS 复配添加 |
| **复合益生元** | 与菊粉、FOS、益生菌联合 |

### 选购要点
- 来源：主流为乳糖酶法合成，关注生产商资质
- 复配：婴幼儿产品关注 GOS:FOS 比例
- 纯度：优质产品应标注 GOS 含量百分比
