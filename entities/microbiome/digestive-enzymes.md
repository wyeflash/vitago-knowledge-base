# 消化酶复合剂

> 含有胰酶、胃蛋白酶、菠萝蛋白酶、木瓜蛋白酶等消化酶的补充剂，用于辅助食物消化、缓解消化不良症状或替代胰腺外分泌功能不足。临床证据在胰腺外分泌功能不全 (EPI) 中最强，功能性消化不良中的应用证据中等。

## Overview

消化酶复合剂（Digestive Enzyme Supplements）是一类通过补充外源性消化酶来帮助分解食物中的宏量营养素（蛋白质、脂肪、碳水化合物）的补充剂。主要分为两类：

1. **胰酶替代疗法 (PERT)**：以胰脂肪酶、胰蛋白酶、胰淀粉酶为主，用于胰腺外分泌功能不全（如囊性纤维化、慢性胰腺炎、胰腺癌术后、胃切除术后等）。
2. **非处方消化酶补充剂**：常含菠萝蛋白酶、木瓜蛋白酶、胃蛋白酶、淀粉酶、脂肪酶、乳糖酶等，用于功能性消化不良、胀气、食物不耐受等症状的辅助缓解。

## Key Facts

| 项目 | 内容 |
|------|------|
| 主要类型 | 胰酶 (脂肪酶+蛋白酶+淀粉酶)、植物/真菌来源酶 |
| 常见来源 | 猪胰提取物、曲霉菌 (Aspergillus)、菠萝、木瓜 |
| 主要用途 | 胰腺外分泌功能不全、功能性消化不良、乳糖不耐受、胀气 |
| 常见剂型 | 肠溶胶囊、普通胶囊、咀嚼片、粉剂 |
| 典型剂量 | 依酶种类和适应症差异极大（见下表） |
| 监管分类 | PERT 为处方药；非处方消化酶为膳食补充剂 |

## Research Evidence

### 胰腺外分泌功能不全 (EPI)
- **金标准适应症**：胰酶替代疗法 (PERT) 是 EPI 的标准治疗，可显著改善脂肪泻、营养不良和体重下降。
- **适应病症**：慢性胰腺炎、囊性纤维化、胰腺癌、全胰切除术后、胃切除术后。
- **剂量**：以脂肪酶活性单位计算，通常每餐 25,000–40,000 USP 单位脂肪酶，随餐服用。

### 功能性消化不良与胀气
- 部分含 α-半乳糖苷酶（如 Beano®）的产品可减少豆类、十字花科蔬菜引起的产气腹胀。
- 含胃蛋白酶和 HCl 的复合制剂对胃酸低下者的消化不良可能有益，但证据有限。
- 菠萝蛋白酶和木瓜蛋白酶对蛋白质消化的辅助作用有传统使用历史和初步研究支持。

### 乳糖不耐受
- 乳糖酶 (lactase) 补充剂是乳糖不耐受最直接有效的非药物干预，可在摄入乳制品前服用，分解乳糖为葡萄糖和半乳糖。
- 效果因产品活性和服用时机而异，对大量乳制品可能需增加剂量。

### 肠易激综合征 (IBS)
- 部分研究显示消化酶（尤其含脂肪酶或蛋白酶）对 IBS-D 和 IBS-M 亚型患者的腹胀、排便症状有改善，但证据质量参差。

### 炎症与运动恢复（菠萝蛋白酶）
- 菠萝蛋白酶 (bromelain) 在高剂量时显示出一定的抗炎和抗水肿作用，常用于术后肿胀和鼻窦炎辅助，但属于蛋白水解酶的全身效应，非消化酶主要用途。

## Mechanisms

| 酶 | 来源 | 作用底物 | 主要功能 |
|----|------|----------|----------|
| **胰脂肪酶** | 猪胰/微生物 | 甘油三酯 | 分解脂肪为游离脂肪酸和单甘酯 |
| **胰蛋白酶/糜蛋白酶** | 猪胰/微生物 | 蛋白质 | 分解蛋白质为多肽和氨基酸 |
| **胰淀粉酶** | 猪胰/微生物 | 淀粉 | 分解淀粉为麦芽糖和葡萄糖 |
| **乳糖酶** | 真菌/酵母 | 乳糖 | 分解乳糖为葡萄糖+半乳糖 |
| **α-半乳糖苷酶** | 真菌 | 棉子糖、水苏糖 | 分解豆类产气寡糖 |
| **菠萝蛋白酶** | 菠萝茎/果 | 蛋白质 | 辅助蛋白质消化；高剂量有抗炎作用 |
| **木瓜蛋白酶** | 木瓜乳胶 | 蛋白质 | 辅助蛋白质消化 |
| **胃蛋白酶** | 猪胃/微生物 | 蛋白质 | 在胃酸环境中分解蛋白质 |

## Populations & Dosage

| 人群/用途 | 酶类型 | 典型剂量 | 证据等级 |
|-----------|--------|----------|----------|
| 胰腺外分泌功能不全 | 胰酶 (PERT) | 25,000–40,000 USP 脂肪酶单位/餐 | 高 |
| 乳糖不耐受 | 乳糖酶 | 3,000–9,000 FCC ALU，随乳制品服用 | 高 |
| 豆类/产气食物胀气 | α-半乳糖苷酶 | 按产品说明，餐前服用 | 中等 |
| 功能性消化不良 | 复合消化酶 | 按产品说明 | 低-中等 |
| 胃酸低下伴消化不良 | 胃蛋白酶+HCl | 按产品说明 | 低 |

### 服用时机
- **脂肪酶/淀粉酶/蛋白酶**：随餐或餐中服用，以与食糜混合
- **乳糖酶**：摄入乳制品前即刻服用
- **α-半乳糖苷酶**：摄入产气食物前服用
- **PERT 肠溶胶囊**：不可嚼碎或打开（破坏肠溶衣），随餐吞服

## Safety

### 常见不良反应
- 恶心、腹部不适、腹泻或便秘
- 口咽刺激（非肠溶胰酶胶囊打开服用时）
- 高剂量胰酶可能引起高尿酸血症（嘌呤含量）

### 安全性总体评价
消化酶在推荐剂量下通常安全。PERT 为长期处方药，安全性数据充分。非处方消化酶的安全性数据相对有限但总体良好。

### 重要注意事项
- **PERT 肠溶胶囊**：囊性纤维化患儿在高剂量 PERT 时曾有结肠狭窄的罕见报道（与高剂量和高肠腔酶活性有关），需遵医嘱使用。
- **猪来源过敏**：猪胰酶产品对猪肉过敏者理论上存在风险，但实际过敏极罕见。
- **急性胰腺炎早期**：急性胰腺炎发作期禁用胰酶（可能刺激胰腺），恢复期后如存在 EPI 再启用。
- **铁吸收**：长期高剂量胰酶可能影响铁吸收，需监测。

## Forms & Quality

| 剂型 | 特点 |
|------|------|
| **肠溶胶囊** | PERT 标准剂型，保护酶不被胃酸破坏 |
| **普通胶囊/片剂** | 非处方消化酶常见形式 |
| **咀嚼片** | 适合儿童或吞咽困难者 |
| **粉剂** | 婴幼儿 PERT 或特殊需求 |
| **缓释微丸** | 先进 PERT 剂型，微丸包衣提高稳定性 |

### 酶活性单位
| 单位系统 | 说明 |
|----------|------|
| **USP (United States Pharmacopeia)** | 美国药典单位，PERT 常用 |
| **FCC (Food Chemicals Codex)** | 食品化学品法典，膳食补充剂常用 |
| **FIP (Fédération Internationale Pharmaceutique)** | 国际药学联合会单位，欧洲常用 |

### 选购要点
- **适应症匹配**：EPI 需处方药 PERT；功能性症状可选非处方复合酶
- **酶活性标注**：关注具体酶的活性单位，非仅看重量
- **肠溶包衣**：胃酸敏感酶（脂肪酶、胰蛋白酶）需肠溶保护
- **过敏原**：关注产品是否含常见过敏原（如麦麸、大豆）
