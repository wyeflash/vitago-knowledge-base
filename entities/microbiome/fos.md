# 低聚果糖

> 短链果聚糖（聚合度 2–9），是菊粉的水解短链形式，也是天然存在于多种植物中的可溶性膳食纤维。作为益生元，其甜度高于长链菊粉，溶解性更好，是婴幼儿配方食品和功能性食品中应用最广泛的益生元之一。

## Overview

低聚果糖（Fructooligosaccharides, FOS）是由 2–9 个果糖单元通过 β-(2→1) 糖苷键连接而成的短链果聚糖，末端通常带一个葡萄糖单元。它是菊粉（长链果聚糖，DP 2–60）的短链部分，也可通过菊粉部分水解或蔗糖酶法转化获得。

天然存在于洋葱、大蒜、菊苣、芦笋、香蕉、小麦等食物中。在婴幼儿营养领域，FOS 常与低聚半乳糖 (GOS) 复配添加于配方奶粉，以模拟母乳低聚糖的益生元效应。

## Key Facts

| 项目 | 内容 |
|------|------|
| 化学类别 | 短链果聚糖 (scFOS)，可溶性膳食纤维 |
| 聚合度 (DP) | 2–9（通常 3–5） |
| 甜度 | 约为蔗糖的 30–50% |
| 主要来源 | 菊苣根、菊芋、洋葱、大蒜、蔗糖酶法合成 |
| 能量值 | 约 1.5 kcal/g |
| 常见剂型 | 粉末、糖浆、食品添加、婴幼儿配方 |
| 典型剂量 | 2.5–10 g/天 |

## Research Evidence

### 肠道菌群调节
FOS 是研究最充分的益生元之一。人体研究显示，每日 2.5–10 g 即可选择性促进双歧杆菌增殖，效果在 1–2 周内显现。与长链菊粉相比，FOS 发酵更快，主要作用于结肠近端。

### 婴幼儿健康
- **配方奶补充**：FOS + GOS 复配（比例通常 1:9 或 1:4）是婴幼儿配方中最常见的益生元组合，可使配方奶喂养婴儿的菌群组成和粪便性状更接近母乳喂养婴儿。
- **便秘**：对婴幼儿和儿童功能性便秘有一定改善作用。

### 矿物质吸收
与菊粉类似，FOS 可促进钙、镁的吸收，尤其在青少年和成人中有一定证据。短链特性使其在结肠近端快速发酵产酸，降低 pH 的效果更明显。

### 血脂与代谢
部分研究显示 FOS 对总胆固醇和甘油三酯有轻度降低作用，但效应量小，临床意义有限。

### 免疫相关
通过调节肠道菌群和短链脂肪酸产生，FOS 可能间接影响肠道免疫，但直接免疫临床终点证据较弱。

## Mechanisms

| 机制 | 说明 |
|------|------|
| 选择性发酵 | 双歧杆菌等优先利用 FOS 作为碳源快速增殖 |
| 快速产酸 | 短链结构发酵速度快，迅速降低肠腔 pH |
| SCFA 生成 | 产生乙酸、丙酸、乳酸；丁酸生成相对较少 |
| 矿物质溶解 | 降低 pH 增加钙、镁离子化程度，促进吸收 |
| 增加粪便体积 | 轻度增加粪便含水量和体积 |
| 病原抑制 | 酸化环境抑制沙门氏菌、产气荚膜梭菌等 |

## Populations & Dosage

| 人群/用途 | 起始剂量 | 维持剂量 | 证据等级 |
|-----------|----------|----------|----------|
| 成人肠道健康 | 2.5–5 g/天 | 5–10 g/天 | 中等 |
| 婴幼儿（配方添加） | 按配方 | 0.4–0.8 g/100 mL | 中等 |
| 便秘 | 5 g/天 | 5–10 g/天 | 低-中等 |
| 钙吸收促进 | 5–8 g/天 | 8–10 g/天 | 低-中等 |

### 使用建议
- 建议与 GOS 复配使用（尤其在婴幼儿产品中）
- 从小剂量起始，逐步增加以减少胃肠不适
- 与足量水同服

## Safety

### 常见不良反应
- 腹胀、胀气（最常见，通常 1–2 周内适应）
- 腹部不适、肠鸣
- 腹泻（剂量过高时）

### 安全性总体评价
FOS 安全性高，FDA 认定为 GRAS。EFSA 批准了相关健康声称。婴幼儿配方中的常规添加量安全。

### 注意事项
- **IBS**：属于 FODMAPs，部分患者不耐受
- **SIBO**：活跃期慎用
- **IBD 急性期**：高纤维可能加重症状
- **果糖吸收不良**：极少数人对 FOS 反应更明显

## Forms & Quality

| 剂型 | 特点 |
|------|------|
| **FOS 粉末** | 最常见，微甜，易溶于水 |
| **FOS 糖浆** | 液体形式，用于食品和饮料工业 |
| **婴幼儿配方添加** | 常与 GOS 复配 |
| **复合益生元产品** | 与菊粉、GOS、益生菌联合 |

### 选购要点
- 来源：菊苣来源或蔗糖来源均可，关注纯度
- 聚合度分布：短链 FOS（DP 3–5）发酵更快
- 复配比例：如与 GOS 复配，注意两者比例
