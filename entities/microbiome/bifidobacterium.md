# 双歧杆菌属

> 革兰氏阳性、不产孢子的厌氧杆菌，是健康人肠道（尤其结肠）和婴儿肠道中数量最占优的细菌属之一。作为益生菌，其对婴儿健康、肠道屏障和免疫发育的研究最为充分。

## Overview

双歧杆菌属（Bifidobacterium）是放线菌门 (Actinobacteria) 的一类专性厌氧细菌，呈 Y 形或分叉状（拉丁文 *bifidus* 意为"分叉的"）。在母乳喂养婴儿的肠道中，双歧杆菌可占肠道菌群总数的 80% 以上；在成人中约占 3–5%，虽占比下降但仍是核心共生菌。

该属包含数十个菌种，其中 *B. animalis* subsp. *lactis*（常简写为 *B. lactis*）、*B. longum*、*B. breve*、*B. infantis* 是益生菌研究和商业应用中最常见的。

## Key Facts

| 项目 | 内容 |
|------|------|
| 分类地位 | 放线菌门 (Actinobacteria)，双歧杆菌目 (Bifidobacteriales) |
| 代谢特征 | 专性厌氧，发酵糖类产乙酸和乳酸（摩尔比约 3:2） |
| 主要栖息地 | 结肠、母乳、婴儿肠道、发酵乳制品 |
| 常见菌种 | *B. animalis* lactis BB-12®、*B. longum* 35624®、*B. infantis* 35624、*B. breve* |
| 常见剂型 | 冻干胶囊、婴儿滴剂/粉剂、酸奶、配方奶粉添加 |
| 典型剂量 | 10⁸–10¹⁰ CFU/天 |

## Research Evidence

### 婴儿健康与配方奶补充
- **婴儿配方奶粉中添加双歧杆菌**（尤其 *B. animalis* lactis BB-12®）可降低配方奶喂养婴儿腹泻发生率、缓解便秘，并使其菌群组成更接近母乳喂养婴儿。
- *B. infantis* 因能有效利用母乳低聚糖 (HMOs) 而备受关注，是"最接近母乳菌群"的菌株之一。

### 肠易激综合征 (IBS)
*B. infantis* 35624® 在多项 RCT 中显示出对 IBS 症状（尤其腹痛、腹胀、排便习惯异常）的改善效果，是目前 IBS 领域证据最强的益生菌菌株之一。

### 便秘
部分双歧杆菌菌株（如 *B. animalis* lactis）对功能性便秘有一定改善作用，可能通过产酸刺激肠蠕动和软化粪便。

### 免疫调节与感染预防
- 婴儿和幼儿中，特定双歧杆菌菌株可能降低呼吸道感染和急性中耳炎的发生率。
- 老年人中，双歧杆菌补充可能增强对疫苗的抗体应答。

### 肠屏障与低度炎症
双歧杆菌产生的乙酸可滋养结肠上皮细胞，短链脂肪酸 (SCFA) 环境有助于维持肠屏障完整性和调节全身低度炎症。

## Mechanisms

| 机制 | 说明 |
|------|------|
| 产酸定植 | 产生乙酸和乳酸，酸化结肠环境，抑制病原菌 |
| HMO 利用 | *B. infantis* 等菌株拥有独特的 HMO 代谢基因簇，在婴儿肠道具有竞争优势 |
| 屏障强化 | 促进黏蛋白分泌和紧密连接蛋白表达 |
| 免疫调节 | 与肠道免疫细胞互作，促进调节性 T 细胞 (Treg) 分化，维持免疫耐受 |
| 病原体拮抗 | 过渡竞争、产生有机酸和细菌素抑制病原菌定植 |
| 胆汁酸代谢 | 参与胆汁酸生物转化，影响宿主脂代谢 |

## Populations & Dosage

| 人群/用途 | 菌株示例 | 典型剂量 | 证据等级 |
|-----------|----------|----------|----------|
| 婴儿腹泻/便秘预防 | *B. animalis* lactis BB-12® | 10⁸–10⁹ CFU/天 | 中等 |
| IBS 症状管理 | *B. infantis* 35624® | 10⁸ CFU/天 | 中等 |
| 功能性便秘 | *B. animalis* lactis | 10⁹–10¹⁰ CFU/天 | 低-中等 |
| 老年人免疫支持 | *B. longum*、*B. breve* | 10⁹–10¹⁰ CFU/天 | 低 |
| 抗生素相关性腹泻预防 | *B. lactis* BB-12®（复方） | 10⁹–10¹⁰ CFU/天 | 低-中等 |

## Safety

### 常见不良反应
- 腹胀、排气增多（通常 1–2 周内缓解）
- 轻度腹部不适

### 安全性总体评价
双歧杆菌对健康人群安全，婴儿和老年人耐受性良好。菌血症/真菌血症病例极其罕见，多见于重症监护或免疫严重抑制患者。

### 禁忌与注意事项
- **早产儿/低出生体重儿**：重症监护中的早产儿使用益生菌存在争议，部分研究中极低体重儿出现罕见严重不良事件，需在医生指导下使用。
- **免疫缺陷患者**：与所有活菌益生菌相同，免疫严重低下者需谨慎。
- **中心静脉导管患者**：建议避免。

## Forms & Quality

| 剂型 | 特点 |
|------|------|
| **冻干胶囊/片剂** | 成人主流剂型，需关注活菌数稳定性 |
| **婴儿滴剂/粉剂** | 专为婴幼儿设计，常含单一或双菌株 |
| **配方奶粉添加** | 婴幼儿配方常见，需注意储存条件 |
| **耐胃酸包埋** | 保护活菌通过胃部到达结肠 |

### 选购要点
- 菌株标识应具体到菌株号
- 关注保质期末活菌数 (CFU)
- 婴儿产品应选择婴幼儿适用菌株（如 BB-12®、*B. infantis*）
