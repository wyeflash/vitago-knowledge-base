# 速查与工具

> `reference/` 是 VitaGo KB 的基础设施层，用于解释全站反复出现的缩写、单位、证据等级、权威来源和剂量估算逻辑。它不直接给出补充建议，而是帮助读者正确理解实体页、概念页、安全页和指引页中的专业表达。

## 子页面

### 基础工具

- [缩写术语表](glossary) — RDA、AI、EAR、UL、NOAEL、LOAEL、RR、NNT 等营养学与循证医学常用缩写
- [计量单位换算](units-conversions) — μg、mcg、mg、IU、mmol 等单位换算，重点覆盖维生素 A/D/E 与电解质
- [剂量计算思路](dose-calculation) — 按年龄、性别、体重与生理状态估算补充剂剂量时的基本框架和边界

### 证据与来源

- [证据等级金字塔](evidence-hierarchy) — 从病例报告到 Cochrane 系统综述、指南与 GRADE 的证据层级说明
- [权威来源索引](authoritative-sources) — NIH ODS、EFSA、Cochrane、ISSN、LPI、NCCIH 等来源的覆盖范围与使用指南


### 法规与标准

- [法规与标准](regulations/) — 各国监管框架、标签法规、第三方认证和跨境电商规则的速查入口
- [各国监管框架对比](regulations/global-frameworks) — 美国、欧盟、中国、日本、澳洲等补充剂监管体系的核心差异
- [标签法规差异](regulations/label-rules) — Supplement Facts、蓝帽子/保健食品标签、欧盟 food supplement 标签的阅读边界
- [第三方认证体系](regulations/certification-standards) — USP、NSF、ConsumerLab、IFOS、GMP、COA、蓝帽子的检查范围与误区
- [进口与跨境电商](regulations/cross-border-ecommerce) — 海淘和跨境电商购买补充剂时的标签、成分、剂量和渠道风险

## 与其他分类的关系

| 分类 | 回答的问题 | 与 reference/ 的关系 |
|------|------------|---------------------|
| [实体](../entities/) | 某个营养素、植物提取物或机构是什么 | 实体页中的缩写、单位和来源可回链到 reference/ |
| [概念](../concepts/) | 机制、功效方向和分类体系如何理解 | 概念页中的证据术语由 reference/ 解释 |
| [安全](../safety/) | 剂量上限、相互作用和禁忌是什么 | UL、NOAEL、LOAEL 等安全术语由 reference/ 统一说明 |
| [指引](../guides/) | 特定人群或场景下如何决策 | 指引页中的剂量估算和证据等级由 reference/ 提供基础 |
| [对比](../comparisons/) | 多个成分、剂型或标准如何选择 | 对比页中的单位、来源和证据强度可引用 reference/ |
## 使用边界

本索引页用于导航和分类，不承载完整证据综述。具体剂量、禁忌、相互作用和证据强度应进入对应实体页、指南页或安全页查看。若页面涉及疾病、孕期、儿童、肝肾功能异常或多药联用，应优先参考权威指南和医师/药师意见。
