# 维甲酸受体（RAR/RXR）信号通路

> 维生素 A 是一种脂溶性类视黄醇，其活性代谢产物 **全反式维甲酸（all-trans retinoic acid, ATRA）** 是核受体转录因子超家族的配体。与 VDR 类似，RAR 必须与 RXR 形成异源二聚体才能结合 DNA。维生素 A 通过 RAR/RXR 调控视觉、免疫、细胞分化和胚胎发育等关键生理过程。

## 核心要点

- **全反式维甲酸（ATRA）是主要活性配体**：维生素 A 在肠壁经脂酮还原酶转化为视黄醇，再经脱氢酶/氧化酶转化为 ATRA。ATRA 是 RARα/β/γ 的高亲和力配体。
- **RAR 必须与 RXR 形成异源二聚体**：RAR 单独不能结合 DNA，必须与 RXR（维甲酸 X 受体）形成 RAR-RXR 异源二聚体。RXR 同时也是 VDR、PPAR、FXR、LXR 等多个核受体的搭档。
- **三个 RAR 亚型分工不同**：RARα 主要在视网膜和肝脏表达；RARβ 在脑部和胚胎发育中关键；RARγ 在皮肤和郑郑组织表达。
- **胚胎发育中不可或缺**：胚胎期维生素 A 缺乏导致神经管缺陷，过量则导致致畴性缾形。
- **RAR 信号具有免疫调节两面性**：既可促进免疫耐受（Treg 分化），又可增强先天免疫（Cathelicidin 表达）。

## 配体代谢与活化

```食物中的维生素 A
    │
    ├── 视黄酸（肋肪、鱼肝油、奶制品）
    │      ↓
    │   肠壁脂酮还原酶 → 视黄酸
    │      ↓
    │   脱氢/氧化 → 全反式维甲酸（ATRA）
    │      ↓
    │   细胞内 CRABP 运输 → 核内 RAR/RXR 二聚体
    │
    └── β-胡萝卜素（深色蔬菜、水果）
           ↓
        肠壁氧化 → 视黄酸 → 经上述同路径
```

**关键转化酶**：
- **RALDH（视黄酸脱氢酶）**：将视黄酸转化为视黄醛，再转化为 ATRA
- **CYP26（细胞色素 P450 家族）**：降解 ATRA，形成负反馈调节

## RAR/RXR 通路机制

### 经典基因组通路

```
ATRA → 穿过细胞膜 → 核内 RARα/β/γ
    ↓
RAR + RXR → 异源二聚体
    ↓
结合 RARE（维甲酸反应元件）
    ↓
转录激活/抑制
```

**经典靶基因**：
- **视觉**：RPE65（视网膜色素上皮修复）、IRBP（视网膜结合蛋白）
- **免疫**：FOXP3（Treg 分化）、Cathelicidin（LL-37）、RAR-related orphan receptor
- **分化**：HOX 基因群（胚胎体节形成）、CYP26（负反馈）

### 非基因组快速通路

- **PI3K/Akt 通路**：影响细胞存活和增殖
- **MAPK 通路**：调控细胞分化

## 三个 RAR 亚型的功能

### RARα

- **主要表达**：视网膜、肝脏、肺、脾脏
- **功能**：
  - 视觉信号转导
  - 肝脏脂质代谢
  - 戒烟中的重要调控因子
- **药物**：全反式维甲酸（ATRA）用于急性早幼粒细胞白血病（APL）治疗，通过 RARα 触发癌细胞分化

### RARβ

- **主要表达**：脑、胎盘、胚胎
- **功能**：
  - 胚胎发育中的神经系统形成
  - 脑部神经发育
  - 内耳毛细胞分化
- **缺乏后果**：胚胎神经管缺陷、小脑发育异常

### RARγ

- **主要表达**：皮肤、超过郑郑组织、肺
- **功能**：
  - 皮肤上皮细胞增殖与分化（involucrin、filaggrin）
  - 魅荡力细胞抗烂痁
  - 肠道免疫调节

## RXR 的核心拔桩作用

RXR 是多个核受体的通用搭桩，形成异源二聚体：

| 受体 | 配体 | 主要功能 |
|------|------|----------|
| **VDR** | 1,25(OH)₂D | 钙磷代谢、骨骼健康 |
| **RAR** | ATRA | 视觉、分化、免疫 |
| **PPAR** | 脂肪酸 | 脂质代谢、炎症 |
| **FXR** | 胆汁酸 | 胆汁酸代谢、肾脏功能 |
| **LXR** | 氧化类固醇 | 胆固醇代谢 |
| **PXR/CAR** | 外源性化合物 | 解毒、药物代谢 |

> **营养学意义**：RXR 配体（9-顺式维甲酸）的搭桩质量可能影响其他核受体的功能，这解释了维生素 A 与 D 在代谢上的协同与竞争关系。

## 与其他通路的交互

- **VDR 通路**：RAR 和 VDR 共享 RXR 搭桩，高剂量维生素 A 可能与维生素 D 竞争 RXR，影响各自通路效率
- **Wnt/β-catenin 通路**：ATRA 可抑制 Wnt 通路，调控细胞分化与增殖
- **BMP 通路**：在胚胎发育中，RAR 信号与 BMP 协同调控神经系统形成
- **NF-κB 通路**：ATRA 可抑制 NF-κB，减少促炎介质

## 人群分层与安全

| 人群 | 关键需求 | 注意事项 |
|------|----------|----------|
| 孕妇 | 胎儿神经系统发育 | 缺乏导致神经管缺陷；过量导致致畴；推荐 770 mcg RAE |
| 婴幼儿 | 视觉发育、免疫成熟 | 严重缺乏导致夜盲症、免疫低下 |
| 儿童 | 生长发育、免疫 | 推荐摄入量随年龄增加 |
| 成年人 | 视觉、免疫、皮肤 | 均衡饮食通常满足需求 |
| 老年人 | 免疫功能、视力 | 吸收效率可能下降 |

**安全上限**：
- 成年男性 UL = 3,000 mcg RAE/天（约 10,000 IU 退黄醇）
- 过量补充可导致肝毒性、中枢神经系统症状、骨骼异常
- 与维生素 D 同补时注意比例，避免 RXR 竞争
