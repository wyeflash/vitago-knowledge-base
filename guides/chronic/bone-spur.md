# 骨刺（骨质增生）患者营养补充指引

> 骨刺（骨质增生）通常是退行性骨关节病变的结果，缺乏针对骨刺本身的专门指南。以下建议基于 OARSI 骨关节炎指南及退行性骨病的营养支持。^[raw/guidelines/oarsi-osteoarthritis-2019.md]

## 核心原则

1. **骨刺是退行性变化的标志**：补充剂不能消除骨刺，可能缓解其引发的症状。
2. **重点是关节保护**：减少机械刺激、增强周围肌肉、控制体重。
3. **抗炎是核心**：降低关节内炎症可能减慢退化进程。
4. **骨健康支持**：确保充足的钙和维生素 D 以支持整体骨骼健康。

## 核心补充剂评估

### 姜黄素

| 项目 | 内容 |
|------|------|
| **机制** | 抗炎（抑制 COX-2、LOX 通路） |
| **证据** | 多项 RCT 显示可缓解 OA 疼痛；对骨刺直接疼痛可能有益 |
| **推荐剂量** | 500-1,000 mg 姜黄素/日（含胡椒碱增加吸收） |
| **评估** | 对轻中度 OA 和骨刺疼痛最有证据 |

### II 型胶原蛋白

| 项目 | 内容 |
|------|------|
| **机制** | 支持软骨和骨骼基质合成 |
| **证据** | UC-II 专利提取物 40 mg/日在 OA 中显示效果 |
| **剂量** | 40 mg/日（专利 UC-II） |
| **评估** | 小型 RCT 阳性；对骨刺可能有益（关节软骨保护） |

### 葡萄糖胺 + 软骨素

| 项目 | 内容 |
|------|------|
| **证据** | 与骨关节炎页面相同；可缓解关节疼痛和功能 |
| **评估** | 适用于并发骨关节炎的骨刺患者 |

### 钙与维生素 D

| 项目 | 内容 |
|------|------|
| **证据** | 确保骨密度和骨骼健康；预防进一步退行性变化 |
| **推荐** | 钙 1,000-1,200 mg/日 + 维生素 D 800-2,000 IU/日 |

## 其他补充剂评估

| 补充剂 | 证据 | 评估 |
|--------|------|------|
| **Omega-3** | 低-中等 | 抗炎作用可能缓解关节症状 |
| **维生素 K2** | 低 | 可能有助于骨代谢；证据不足 |
| **硫酸软骨素** | 低 | 一些小型研究阳性；证据较弱 |
| **玻璃酸钠（HA）** | 低 | 关节液的主要成分；口服证据不足 |

## 非补充剂核心干预

1. **减轻机械刺激**：避免过度使用受影响关节。
2. **体重管理**：减少关节负担。
3. **理疗**：冷敷/热敷、按摩、超声波。
4. **适度运动**：低冲击运动（游泳、骑车、太极拳）。

## 安全性与警告

- **姜黄素**：高剂量可致胃肠不适；与抗凝药联用需监测。
- **钙补充**：分次服用，与饮食同时服用吸收更好。
