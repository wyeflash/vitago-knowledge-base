# 慢性免疫力低下患者营养补充指引

> 基于 WHO 微量营养素与免疫功能的科学共识及相关临床证据。**注意："免疫力低下"是一个较主观的概念，首先应排除原发性免疫缺陷病、自身免疫病、癌症、药物等明确原因。**^[raw/guidelines/immune-supplement-evidence.md]

## 核心原则

1. **排除根本原因**：营养缺乏是可逆因素，但先排除病理性原因。
2. **均衡饮食是基础**：任何单一补充剂不能替代整体营养状况。
3. **睡眠和压力管理**：对免疫功能的影响不亚于营养。
4. **补充剂仅作为辅助**：在确认缺乏或特殊需求时使用。

## 核心补充剂评估

### 维生素 D

| 项目 | 内容 |
|------|------|
| **机制** | 调节免疫细胞分化、抗炎反应；维持防御功能 |
| **证据** | 缺乏与呼吸道感染风险增加相关；补充后可能降低感染风险 |
| **推荐剂量** | 根据基线：一般 2,000-4,000 IU/日 |
| **监测** | 建议检测 25(OH)D；目标 ≥30 ng/mL |
| **评估** | 最有证据支持的免疫相关补充剂 |

### 锌

| 项目 | 内容 |
|------|------|
| **机制** | 参与 T 细胞分化、自然杀伤细胞功能、烂细胞产生 |
| **证据** | 缺乏损害天然免疫和适应性免疫；补充可缩短普通感冒持续时间 |
| **推荐剂量** | 15-30 mg 元素锌/日（酸性以外的形式如葡萄糖酸锌） |
| **最佳人群** | 锌缺乏者、老年人、植物性饮食者 |
| **评估** | 长期高剂量可影响铜吸收；不建议超过 40 mg/日超过 2 周 |

### 维生素 C

| 项目 | 内容 |
|------|------|
| **机制** | 抗氧化；支持白细胞功能 |
| **证据** | 高剂量（1-2 g/日）可能减轻普通感冒症状和持续时间 |
| **推荐剂量** | 200-1,000 mg/日（预防级）；感染期间可增至 1-2 g/日 |
| **评估** | 对预防感染的证据不一致；对减轻症状更有证据 |

### 接骨木莓（Elderberry）

| 项目 | 内容 |
|------|------|
| **机制** | 含花青素，具抗毒和抗炎作用 |
| **证据** | 多项小型 RCT 显示可缩短流感持续时间和减轻症状 |
| **推荐剂量** | 依产品说明（通常含 300-500 mg 提取物） |
| **评估** | 对流感和上呼吸道感染可能有益；对其他感染的证据有限 |

## 其他补充剂评估

| 补充剂 | 证据 | 评估 |
|--------|------|------|
| **益生菌** | 中等 | 特定菌株可调节免疫响应；对呼吸道感染的预防作用有初步证据 |
| **钒** | 低 | 抗氧化和免疫调节作用；但证据不足以支持常规补充 |
| **ß-葡聚糖（Beta-glucan）** | 中等 | 可能增强免疫响应；常见于葡萄黑面包酱和金针菇提取物 |
| **蚂蚁木提取物** | 低 | 传统中药用于增强免疫；现代证据有限 |

## 饮食建议

- **充足的蛋白质**：免疫细胞的合成需要氨基酸。
- **多种蔬菜水果**：提供抗氧化剂、维生素和矿物质。
- **健康脂肪**：橄榄油、坚果、鱼类中的不饱和脂肪。
- **发酵食品**：酸奶、胀菜、酱油、酱菜可提供益生菌。
- **限制精制糖和超加工食品**。

## 生活方式干预

| 干预 | 证据强度 | 说明 |
|------|---------|------|
| **规律睡眠** | 强 | 睡眠不足可直接抑制免疫功能 |
| **运动** | 中 | 适度运动可增强免疫监视和迫害功能 |
| **压力管理** | 中 | 长期压力可导致免疫功能低下 |
| **戒烟** | 强 | 吸烟损害呼吸道免疫屏障 |

## 特殊人群

### 老年人
- 免疫功能随年龄增长而自然衰退（免疫衰老）。
- 维生素 D 和锌的补充可能更有益。
- 蛋白质需求可能更高；确保充足摄入。

### 儿童
- 免疫系统尚未发育成熟；注意拉萨米的预防接种。
- 补充剂应更加谨慎；避免高剂量维生素 A 和 D。

### 病后/手术后
- 免疫功能可能暂时受损。
- 重点是蛋白质、维生素 C、维生素 D 和锌的充足摄入。

## 安全性与警告

- **维生素 D 过量**：>10,000 IU/日长期可致毒性。
- **锌过量**：>40 mg/日可致铜缺乏、恶心、呕吐。
- **免疫激活剂**：避免未证实安全的"免疫增强"产品。
- **自身免疫病**：补充剂可能影响病情，需在医生指导下使用。
