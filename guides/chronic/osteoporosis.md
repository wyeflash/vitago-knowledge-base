# 骨质疏松患者营养补充指引

> 基于 2019 年欧洲绝经后女性骨质疏松诊断与管理指南（IOF/ESCEO）及 IOM DRI，为骨质疏松高危人群和患者提供营养补充决策支持。^[raw/guidelines/european-osteoporosis-2019.md]

## 指引概览

骨质疏松症以骨量减少和骨微结构破坏为特征，导致骨折风险增加。营养干预是所有防治策略的基础，**钙和维生素 D 是证据最强、最广泛推荐的补充剂**。其他营养素（维生素 K2、镁、胶原蛋白）的证据正在积累中。^[raw/guidelines/european-osteoporosis-2019.md]

## 核心补充剂推荐

### 钙（Calcium）

| 项目 | 内容 |
|------|------|
| **推荐摄入量** | 1,000-1,200 mg/日（饮食 + 补充剂总量） |
| **19-50 岁** | 1,000 mg/日 |
| **>50 岁女性 / >70 岁男性** | 1,200 mg/日 |
| **最佳补充方式** | 分次服用，单次 ≤500 mg（吸收率最佳） |
| **形式选择** | 碳酸钙（随餐服用，需胃酸）；柠檬酸钙（空腹也可，吸收不受胃酸影响） |

> **食物优先**: 乳制品（牛奶、酸奶、奶酪）、深绿色蔬菜（羽衣甘蓝、西兰花）、豆腐、杏仁、沙丁鱼（带骨）。

### 维生素 D

| 项目 | 内容 |
|------|------|
| **推荐摄入量** | 800-2,000 IU/日 |
| **目标血药浓度** | 25(OH)D ≥50 nmol/L（≥20 ng/mL） |
| **高危人群** | 老年人、居家/机构居住者、深色皮肤、高纬度地区、肥胖者 |
| **监测建议** | 高危人群或长期补充者建议检测 25(OH)D 水平 |

> 维生素 D 促进肠道钙吸收；缺乏时即使高钙摄入也无法有效利用。

### 维生素 K2（MK-7）

| 项目 | 内容 |
|------|------|
| **作用机制** | 激活骨钙素（osteocalcin），促进钙沉积于骨骼 |
| **剂量** | 90-180 mcg/日（MK-7 形式） |
| **证据** | 多项 RCT 显示可改善骨密度和骨强度指标；尚未纳入核心指南，但欧洲部分专家共识支持 |
| **注意** | 使用华法林者禁用（维生素 K 拮抗华法林作用） |

### 镁

| 项目 | 内容 |
|------|------|
| **推荐摄入量** | 310-320 mg/日（女性）；400-420 mg/日（男性） |
| **作用** | 维生素 D 代谢的辅因子；骨基质成分 |
| **来源** | 坚果、种子、全谷物、深绿色蔬菜、黑巧克力 |
| **注意** | 慢性腹泻、吸收不良、长期使用 PPI 者易缺乏 |

## 其他补充剂评估

| 补充剂 | 证据 | 评估 |
|--------|------|-------|
| **胶原蛋白肽** | 新兴 | 部分 RCT 显示小幅度 BMD 改善；机制可能涉及刺激成骨细胞 |
| **硼（Boron）** | 不足 | 动物实验支持；人体证据不充分 |
| **硅（Silica）** | 不足 | 对骨骼矿化可能重要，但补充证据有限 |
| **锶（Strontium）** | 药物级有效 | 雷奈酸锶（处方）在欧洲使用，但因心血管风险受限制；不推荐使用非处方锶补充剂 |
| **大豆异黄酮** | 混合 | 对绝经后女性骨密度有轻微益处；证据不一致 |

## 饮食模式建议

1. **地中海饮食**: 与较好的骨密度和较低的骨折风险相关。
2. **充足蛋白质**: 老年人每日 1.0-1.2 g/kg（预防肌肉减少和骨质流失）。
3. **限盐**: 高钠增加尿钙排泄。
4. **限咖啡因**: 过量（>4 杯咖啡/日）可能增加钙流失。
5. **限酒**: 过量饮酒损害成骨细胞功能。

## 运动建议

- **负重运动**: 步行、慢跑、跳舞、爬楼梯。
- **抗阻训练**: 每周 2-3 次，增强肌肉和骨骼。
- **平衡训练**: 太极拳、瑜伽，预防跌倒。

> ⚠️ **已发生椎体骨折者避免脊柱前屈动作**（如仰卧起坐）。

## 特殊人群

### 绝经后女性
- 骨质疏松最高发人群；FRAX 工具用于评估 10 年骨折风险。
- 药物治疗（双膦酸盐、地诺单抗等）适用于高危患者。

### 老年人（>65 岁）
- 钙和维生素 D 吸收率下降；常需更高剂量补充。
- 蛋白质摄入常不足；建议监测并必要时补充。
- 跌倒预防与营养干预同等重要。

### 长期使用糖皮质激素
- 继发性骨质疏松最常见原因；需积极补钙（1,200-1,500 mg/日）和维生素 D。
- 必要时加用抗骨质疏松药物。

## 安全性与警告

- **肾结石风险**: 高剂量钙补充剂（>1,500 mg/日）可能增加肾结石风险；食物优先，分次小剂量补充。
- **心血管争议**: 部分观察性研究提示钙补充剂（非饮食钙）可能与心血管事件相关；证据不一致，但高剂量补充应谨慎。
- **维生素 D 过量**: >4,000 IU/日长期补充可能导致高钙血症；常规剂量安全。
- **华法林与维生素 K**: 维生素 K2 补充剂可能影响华法林抗凝效果，需监测 INR。
