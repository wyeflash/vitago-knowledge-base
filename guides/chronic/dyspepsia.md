# 消化不良患者营养补充指引

> 基于 ACG 2017 消化不良诊断与管理指南。消化不良分为有机化性和功能性两大类，补充剂主要适用于功能性消化不良的辅助管理。^[raw/guidelines/acg-dyspepsia-2017.md]

## 核心原则

1. **首先排除有机化原因**：H. pylori 感染、溢流性食管炎、胃溃疡、胃癌等。
2. **PPI 试验**：对于未证实的消化不良，短期 PPI 试验有诊断价值。
3. **饮食习惯**：进食速度、分量、触发因素的识别。
4. **补充剂仅作为辅助**：特别是对于功能性消化不良。

## 核心补充剂评估

### 姜粉

| 项目 | 内容 |
|------|------|
| **机制** | 促胃排空、抗炎、减少恶心 |
| **证据** | 多项小型 RCT 显示可缓解功能性消化不良的腹胀、早饱和胃排空延迟 |
| **推荐剂量** | 1-2 g 姜粉/日 |
| **最佳人群** | 以胃排空延迟和早饱为主的消化不良患者 |
| **评估** | 安全性高，证据中等 |

### 朝鲜薹

| 项目 | 内容 |
|------|------|
| **机制** | 刺激胆汁分泌、促进脂肪消化 |
| **证据** | 小型 RCT 显示可缓解胆汁消化不良和腹胀 |
| **推荐剂量** | 320-640 mg 朝鲜薹提取物/日 |
| **评估** | 对脂肪消化不良较有益 |

### 酶补充剂

| 项目 | 内容 |
|------|------|
| **机制** | 补充消化酶不足 |
| **证据** | 对酶不足者有益；对功能性消化不良证据有限 |
| **推荐剂量** | 依产品说明，餐前服用 |
| **最佳人群** | 年老者、肠切除后、胃切除后酶不足者 |

## 其他补充剂评估

| 补充剂 | 证据 | 评估 |
|--------|------|------|
| **益生菌** | 低-中等 | 特定菌株可能改善胃肠功能 |
| **蕉可** | 低 | 传统用于处理胃液分泌；证据有限 |
| **苹果醋** | 低 | 可能对满腹感有轻度改善 |

## 饮食建议

- **小餐多食**：避免每次大量进食。
- **细嚼慢咽**：减少吞气、促进消化酶作用。
- **避免食后即躺**：特别是有食管反流症状者。
- **限制刺激性食物**：辛辣、油腻、过酸食物。
- **限制咖啡因和酒精**。

## 生活方式干预

| 干预 | 证据强度 | 说明 |
|------|---------|------|
| **压力管理** | 中 | 功能性消化不良与压力、焦虑相关 |
| **规律运动** | 低-中 | 轻度活动可促进胃肠蠕动 |
| **戒烟** | 中 | 吸烟可加重消化不良 |

## 特殊人群

### 服用 NSAIDs 者
- 可致药物性胃黏膜损伤。
- PPI 是一线保护；补充剂仅作为辅助。

### 有食管反流者
- 薄荷油可能恶化反流。
- 姜粉也可能在某些人中加重烧心。

## 安全性与警告

- **姜粉**：高剂量可致胃烧心；胃溃疡患者谨用。
- **酶补充剂**：过敏者避用。
- **保護午觉**：长期消化不良应排除胃癌等严重疾病。
