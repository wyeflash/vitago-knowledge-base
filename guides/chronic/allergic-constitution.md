# 过敏性体质营养补充指引

> 基于 ARIA 2023 更新及 EAACI 指南。"过敏性体质"是一个泛指概念，包括过敏性鼻炎、濕疹、咳嗽、食物过敏等。补充剂主要作为药物治疗的辅助。^[raw/guidelines/aria-allergic-rhinitis-2023.md]

## 核心原则

1. **避免触发因素是首选**：补充剂不能替代避免过敏原。
2. **抗组胺 H1 阻滞剂是一线**：尤其是二代药物（西替利喻、氯雷他定等）。
3. **免疫调节是目标**：补充剂可能调节 Th1/Th2 平衡。
4. **注意安全性**：某些补充剂可能诱发过敏反应。

## 核心补充剂评估

### 维生素 D

| 项目 | 内容 |
|------|------|
| **机制** | 调节免疫响应，促进调节性 T 细胞（Treg）功能 |
| **证据** | 缺乏者补充后过敏症状可能改善；但预防过敏的证据不足 |
| **推荐剂量** | 2,000-4,000 IU/日（根据基线） |
| **评估** | 最有前景的过敏相关补充剂之一 |

### Omega-3（EPA/DHA）

| 项目 | 内容 |
|------|------|
| **机制** | 抗炎（降低 IgE 介导的炎症） |
| **证据** | 妇女期间和婴幼儿期间补充可能降低子代过敏风险；成人补充证据不一致 |
| **推荐剂量** | 1,000-2,000 mg EPA+DHA/日 |
| **评估** | 安全性高；对过敏性鼻炎可能有轻度益处 |

### 椀皮素（Quercetin）

| 项目 | 内容 |
|------|------|
| **机制** | 天然抗组胺和抗炎剂；稳定肥大细胞 |
| **证据** | 小型 RCT 显示可减轻过敏性鼻炎症状 |
| **推荐剂量** | 500-1,000 mg/日（特定提取物） |
| **评估** | 证据初步但有前景；安全性高 |

### 寻麻提取物（Stinging Nettle）

| 项目 | 内容 |
|------|------|
| **机制** | 抗组胺和抗炎作用 |
| **证据** | 小型研究显示可缓解过敏性鼻炎症状 |
| **推荐剂量** | 300-600 mg 根提取物/日 |
| **评估** | 传统药用植物；证据有限但安全性高 |

## 其他补充剂评估

| 补充剂 | 证据 | 评估 |
|--------|------|------|
| **益生菌** | 低-中等 | 孕期和婴幼儿期补充可能降低子代过敏风险（脑-肠轴调节） |
| **越橄榄叶提取物** | 低 | 抗炎和抗过敏作用；对过敏性鼻炎可能有益 |
| **蜜蜂产品** | 低 | 蜂胶、蜂蜜在传统医学中被认为有益；现代证据不足 |
| **黄瓜素（Cucurbitacin）** | 低 | 传统用于过敏；证据有限 |

## 饮食建议

- **识别并避免食物过敏原**：如牛奶、鸡蛋、花生、海鲜、小麦等。
- **抗炎饮食**：橄榄油、深海鱼、坚果、鲜色蔬菜。
- **限制高组胺食物**：发酵食品、乳制品、酒精可含组胺，可加重过敏。
- **高纤维饮食**：支持肠道健康和免疫调节。

## 生活方式干预

| 干预 | 证据强度 | 说明 |
|------|---------|------|
| **室内环境控制** | 强 | 尘蟀蟀、花粉、宠物皮屑等过敏原的减少 |
| **洗鼻** | 中 | 海盐水或生理盐水冲洗鼻腔可减轻鼻炎 |
| **压力管理** | 中 | 压力可加重过敏症状 |
| **睡眠** | 中 | 失眠与过敏症状加重相关 |

## 特殊人群

### 孕期
- 维生素 D 和 Omega-3 补充可能降低子代过敏风险。
- 避免尝试未证实安全的补充剂。

### 儿童
- 食物过敏的识别和避免是核心。
- 补充剂证据有限；重点是均衡饮食。

## 安全性与警告

- **花粉症**：补充剂可能诱发严重花粉症，服用时注意。
- **空气净化剂**：不能替代室内环境控制。
- **脱敏治疗**：对于确诊过敏，脱敏是唯一有长期效果的治疗。
