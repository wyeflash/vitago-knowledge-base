# 多囊卵巢综合征（PCOS）患者营养补充指引

> 基于 Endocrine Society 2013 年 PCOS 临床诊疗指南及此后积累的循证证据，为 PCOS 患者提供营养补充决策支持。^[raw/guidelines/endocrine-pcos-2013.md]

## 指引概览

PCOS 是最常见的妇科内分泌疾病，影响 6-12% 的育龄女性。核心特征包括高雄激素血症、排卵障碍和卵巢多囊样改变。胰岛素抵抗是大多数 PCOS 患者的核心病理生理机制。**生活方式干预（减重 5-10%）是首选治疗**，补充剂可作为辅助手段改善代谢和生育结局。^[raw/guidelines/endocrine-pcos-2013.md]

## 核心补充剂推荐

### 肌醇（Myo-inositol）

**PCOS 领域中证据最强、最被广泛推荐的补充剂。^[raw/guidelines/endocrine-pcos-2013.md]**

| 项目 | 内容 |
|------|------|
| **作用机制** | 作为胰岛素信号通路的第二信使，改善胰岛素敏感性 |
| **推荐剂量** | 2,000-4,000 mg/日（通常分 2 次服用） |
| **证据** | 多项 RCT 和荟萃分析显示：改善空腹胰岛素、HOMA-IR、睾酮水平；恢复排卵率提高（尤其 2:1 myo:DCI 比例） |
| **适用人群** | 胰岛素抵抗型 PCOS、计划怀孕者 |
| **安全性** | 极佳；偶见轻微 GI 不适 |

> 2013 年指南时尚未将肌醇纳入核心推荐，但 2018 年后的国际指南和专家共识已将其列为一线辅助选择。

### 维生素 D

| 项目 | 内容 |
|------|------|
| **流行病学** | PCOS 患者中维生素 D 缺乏率高达 70-85% |
| **推荐剂量** | 根据基线水平调整：一般 2,000-4,000 IU/日 |
| **目标浓度** | 25(OH)D ≥30 ng/mL |
| **证据** | 补充维生素 D 可改善：胰岛素抵抗、血脂谱、炎症标志物；部分研究显示 AMH 和排卵率改善 |
| **检测建议** | 所有 PCOS 患者均应检测 25(OH)D |

### Omega-3 脂肪酸

| 项目 | 内容 |
|------|------|
| **推荐剂量** | 1,000-2,000 mg/日（EPA+DHA） |
| **证据** | 改善甘油三酯、降低炎症（CRP、TNF-α）；对雄激素水平和月经规律性可能有轻度改善 |
| **适用场景** | 合并血脂异常、炎症标志物升高者 |

## 其他补充剂评估

| 补充剂 | 证据 | 评估 |
|--------|------|------|
| **铬（Chromium picolinate）** | 低-中等 | 200-1,000 mcg/日；部分 RCT 显示空腹血糖和胰岛素改善；总体证据不一致 |
| **NAC（N-乙酰半胱氨酸）** | 低-中等 | 1,200-1,800 mg/日；部分研究胰岛素抵抗改善类似二甲双胍；排卵率可能提高 |
| **小檗碱（Berberine）** | 新兴 | 500 mg 每日 2-3 次；改善胰岛素敏感性和脂质谱；注意与 CYP3A4 底物的相互作用 |
| **锌** | 低 | 与 PCOS 相关炎症和痤疮可能有改善作用；缺乏专门 RCT |
| **镁** | 低 | 与胰岛素抵抗相关；缺乏 PCOS 专门研究 |
| **辅酶 Q10** | 低 | 可能改善卵子质量；主要证据来自 IVF 人群 |

## 生活方式干预（基石）

1. **减重**
   - 减重 5% 可改善代谢参数。
   - 减重 5-10% 可恢复自发排卵。
   - GLP-1 受体激动剂（如司美格鲁肽）在肥胖 PCOS 中显示显著获益。

2. **饮食模式**
   - 低升糖指数（低 GI）饮食优于单纯热量限制。
   - 地中海饮食模式有益。
   - 限制精制碳水化合物和添加糖。

3. **运动**
   - 每周 ≥150 分钟中等强度有氧运动。
   - 抗阻训练改善胰岛素敏感性。

## 特殊场景

### 计划怀孕
- **肌醇**是备孕 PCOS 患者最值得尝试的补充剂（2-4 g/日）。
- 二甲双胍可改善排卵率和活产率（指南推荐）。
- 叶酸 400 mcg/日（与所有育龄女性相同）。

### 合并 2 型糖尿病前期
- 生活方式干预 + 二甲双胍是标准治疗。
- 肌醇和维生素 D 可作为辅助。

### 合并痤疮/多毛症
- 补充剂对症状的直接改善有限。
- 药物治疗（螺内酯、口服避孕药）更有效。

### 青少年 PCOS
- 以生活方式干预为主。
- 肌醇安全性良好，可考虑。
- 避免未经充分验证的补充剂。

## 安全性与警告

- **小檗碱与药物相互作用**：抑制 CYP3A4 和 P-gp，可能影响他汀类、免疫抑制剂、降压药代谢。
- **NAC**：高剂量可能引起恶心、呕吐。
- **铬**：长期高剂量（>1,000 mcg/日）可能有肾毒性风险。
- **肌醇**：非常安全；GI 副作用轻微且短暂。
