# 特定人群营养指引

> 本目录收录非疾病主导的人群营养补充指引，包括生命周期、生理状态、生活方式和饮食模式人群。疾病或长期健康状态请进入 [慢病患者补充指引](../chronic/)。

| 人群 | 页面 | 定位 |
|------|------|------|
| 孕期与哺乳期 | [孕期与哺乳期营养补充指引](pregnancy) | 叶酸、铁、DHA、碘、胆碱等孕产期核心营养素 |
| 婴幼儿与儿童 | [婴幼儿与儿童营养补充指引](infant-child) | 0–5 岁喂养、辅食与关键补充 |
| 青少年 | [青少年营养补充指引](adolescent) | 骨量积累、铁状态、运动与安全边界 |
| 老年人 | [老年人营养补充指引](senior) | 蛋白质、维生素 D、B12、钙、肌少症和多重用药 |
| 运动人群 | [运动人群营养补充指引](athlete) | 蛋白质、肌酸、电解质、恢复和产品检测 |
| 素食/纯素人群 | [素食/纯素人群营养补充指引](vegetarian) | B12、铁、锌、钙、维生素 D、Omega-3 和蛋白质质量 |
| 围绝经期女性 | [围绝经期女性营养补充指引](perimenopause) | 骨骼、肌肉、心血管代谢风险、睡眠和草本安全边界 |

## 使用边界

本索引页用于导航和分类，不承载完整证据综述。具体剂量、禁忌、相互作用和证据强度应进入对应实体页、指南页或安全页查看。若页面涉及疾病、孕期、儿童、肝肾功能异常或多药联用，应优先参考权威指南和医师/药师意见。
