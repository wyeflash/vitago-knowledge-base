# 检测协议与流程

> 了解如何检测、何时检测、检测前需要做什么准备，可以帮助你获得更可靠的结果，避免不必要的重复检测和资源浪费。

## 自测 vs 医疗机构检测

| 维度 | 家庭自测 | 医疗机构 |
|------|----------|----------|
| **可获性** | 较高（Omega-3 指数、维生素 D、铁蛋白等均有家测套盒） | 需预约或就诊 |
| **准确性** | 中等，取样方式和操作影响结果 | 高，标准化流程和质控 |
| **解读支持** | 一般缺乏，需自行理解或咨询专业人士 | 医生可解读并给出建议 |
| **成本** | 中等（200–800 元/项） | 可医保报销部分项目 |
| **适合场景** | 日常监测、运动营养、定期追踪 | 疑似疾病、复杂情况、治疗方案调整 |

## 检测频率建议

| 指标 | 无风险人群 | 风险人群 | 补充期间 |
|------|----------|----------|------------|
| 25(OH)D | 1–2 年/次 | 每年 | 开始补充后 3 个月复查 |
| 铁蛋白 | 不需要 | 每年 | 补铁后 8–12 周复查 |
| Hcy | 不需要 | 每年 | B 族补充后 3 个月复查 |
| Omega-3 指数 | 不需要 | 每 6 个月 | 调整剂量后 4 个月复查 |
| 血红蛋白 | 每 1–2 年 | 每年 | 贫血治疗后 4–8 周复查 |
| 血清 B12 | 不需要 | 每 1–2 年 | 补充后 3 个月复查 |

## 检测前准备

### 停止补充剂
为了获得真实的"基线"数据，建议在采血前暂停以下补充剂：

| 补充剂 | 建议停补周期 | 理由 |
|--------|------------|------|
| 维生素 D | 无需停用 | 25(OH)D 半衰期 2 周，反映长期状态 |
| 铁剂 | 1–2 天 | 可影响血清铁水平 |
| 叶酸/维生素 B12 | 3–7 天 | 可影响 Hcy 和红细胞叶酸 |
| 高剂量维生素 C | 1–2 天 | 可影响铁和某些检测方法 |
| 鱼油/Omega-3 | 3–7 天 | 可影响脂质分析 |
| 锌 | 1–2 天 | 可影响血清锌水平 |

### 空腹要求
- 大多数营养相关血液检测**不需要严格空腹**，但建议采血前 2–4 小时避免高脂餐食，以免影响脂质分析。
- 如果与其他需要空腹的检测（如血糖、肾功能）同时进行，建议空腹采血。

### 其他注意事项
- **时间**：避开急性感染期或炎症发作期（铁蛋白、血沉等指标可能受影响）。
- **月经**：女性铁蛋白在月经期往往较低，建议选择月经结束后 1–2 周检测。
- **运动**：剧烈运动后 24 小时内可能影响部分指标。

## 检测流程步骤

1. **确定目标**：你想了解什么？是否缺乏某种营养素，还是评估补充效果？
2. **选择指标**：根据目标和风险因素选择最有价值的 1–3 项指标，避免过度检测。
3. **选择渠道**：家庭自测（方便、快捷）或医疗机构（可靠、可解读）。
4. **检测前准备**：停用应影响结果的补充剂，遵循采血前的饮食和时间要求。
5. **采样检测**：遵循采样指南，确保采样方法正确。
6. **解读结果**：参考 [结果解读指南](interpreting-results)，了解你的数值意味着什么。
7. **制定行动计划**：根据结果决定是否需要调整饮食、补充剂或寻求医学建议。
8. **定期复查**：根据指标和干预措施设定复查时间。

## 特殊人群检测注意事项

| 人群 | 特殊考量 |
|------|----------|
| **孕妇** | 部分指标参考范围与非孕妇不同；标准检测包通常包含铁、叶酸、维生素 D、B12 |
| **儿童** | 参考范围随年龄差异很大；采血量和采样方法与成人不同 |
| **老年人** | 部分指标的"正常"范围可能与年轻人不同；多重用药可影响检测结果 |
| **慢性病患者** | 肾功能、肝功能可影响营养素代谢；检测前告知医生当前用药情况 |
