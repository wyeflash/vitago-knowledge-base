# 钙盐形式对比

## 对比目的

市面上钙补充剂种类繁多，不同钙盐在元素钙含量、吸收条件、胃肠耐受性等方面差异显著。本页旨在帮助用户根据自身健康状况、用药情况及预算，选择最适合自己的钙盐形式。

---

## 钙盐对比表

| 特性 | 碳酸钙<br>Calcium carbonate | 柠檬酸钙<br>Calcium citrate | 磷酸钙（微精化）<br>MCP | 苹果酸钙<br>Calcium malate | 酸囊叶钙 | 乳酸钙<br>Calcium lactate |
|---|---|---|---|---|---|---|
| **元素钙含量** | ~40% | ~21% | ~40% | ~30% | ~32% | ~13% |
| **是否需要胃酸** | ✅ 需要 | ❌ 不需要 | ❌ 不依赖 | ❌ 不需要 | 部分需要 | ❌ 不需要 |
| **服用时机** | 随餐服用 | 空腹或随餐均可 | 空腹或随餐均可 | 空腹或随餐均可 | 随餐更佳 | 空腹或随餐均可 |
| **典型吸收率** | ~27% | ~35% | 较高 | 较好 | 中等 | 较好 |
| **溶解度** | 低（依赖胃酸） | 好 | 很好（颗粒小） | 好 | 中等 | 好 |
| **胃肠耐受性** | 一般，易胀气/便秘 | 较好 | 较好 | 好 | 中等 | 好 |
| **价格** | 💰 最便宜 | 💰💰 中等 | 💰💰💰 较贵 | 💰💰 中等 | 💰💰 中等 | 💰💰 中等 |
| **适用人群** | 胃酸正常、健康成人 | 老年人、PPI使用者、胃酸不足者 | 追求高效吸收者 | 胃肠敏感者 | 一般补充者 | 儿童、吞咽困难者（液体剂型） |

## 选择决策树

```
开始
 │
 ├─ 是否正在使用 PPI（质子泵抑制剂）或胃酸分泌不足？
 │   ├─ 是 → 优先选择：柠檬酸钙 / MCP / 苹果酸钙
 │   └─ 否 → 继续
 │
 ├─ 是否有胃肠不适（胀气、便秘）？
 │   ├─ 是 → 优先选择：柠檬酸钙 / 苹果酸钙 / 乳酸钙
 │   └─ 否 → 继续
 │
 ├─ 是否追求性价比？
 │   ├─ 是 → 碳酸钙（随餐服用）
 │   └─ 否 → 继续
 │
 └─ 是否追求最高吸收效率？
     ├─ 是 → MCP（微精化磷酸钙）或 柠檬酸钙
     └─ 否 → 柠檬酸钙（综合最优）
```

### 按人群推荐

| 人群 | 推荐钙盐 | 理由 |
|---|---|---|
| **健康成年人** | 碳酸钙 | 含量高、价格便宜，随餐服用即可 |
| **老年人（>65岁）** | 柠檬酸钙 / MCP | 胃酸分泌下降，不依赖胃酸更易吸收 |
| **PPI / H2受体拮抗剂使用者** | 柠檬酸钙 / 苹果酸钙 / MCP | 胃酸被抑制，碳酸钙溶解差 |
| **胃肠敏感者** | 苹果酸钙 / 柠檬酸钙 | 溶解度好，胃肠刺激小 |
| **儿童** | 乳酸钙 / 柠檬酸钙 | 溶解度好，可做成液体或咀嚼片 |
| **素食者** | 柠檬酸钙 / 苹果酸钙 | 注意碳酸钙可能来源于牡蛎壳 |

## 服用建议

- **单次剂量**：每次 ≤ 500mg 元素钙，超过此量吸收率显著下降
- **服用频率**：分 2–3 次服用，比单次大剂量更有效
- **与铁、锌隔开**：钙会抑制铁、锌吸收，建议间隔 ≥ 2 小时
- **与维生素 D 同服**：维生素 D 可显著提升钙的吸收率
- **避免与草酸/植酸高的食物同服**：如菠菜、茶，会形成不溶性钙盐
