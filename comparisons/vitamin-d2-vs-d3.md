# 维生素 D2 vs D3 对比

## 对比目的

维生素 D2（麦角固化醇，ergocalciferol）和 D3（胆固化醇，cholecalciferol）是补充剂中最常见的两种形式。尽管两者在治愈佛僧病方面能力相当，但在提升和维持血浆 25(OH)D 水平方面存在重要差异。本页帮助用户理解这些差异，做出更精准的选择。

---

## D2 与 D3 对比总表

| 特性 | 维生素 D2（Ergocalciferol） | 维生素 D3（Cholecalciferol） |
|---|---|---|
| **化学来源** | 植物（约类固醇） | 动物（胆固醇） |
| **天然来源** | 橙子、玉米、小麦作物；UV 照射后的蘑菇 | 多脂鱼、鱼肝油、蛋黄、牛肝；皮肤 UVB 合成 |
| **动物性食品中 25(OH)D** | 极少 | 牛肉、猪肉、鸡肉、鸡蛋中含有 25(OH)D3（效力约为 D3 的 5 倍） |
| **肖化道吸收** | 良好 | 良好（与 D2 相当） |
| **提升 25(OH)D 的效率** | 较低 | 更高，同等剂量下血浆 25(OH)D 升高幅度更大 |
| **25(OH)D 维持时间** | 较短 | 更长（血浆浓度下降更慢） |
| **稳定性** | 对氧化更敏感，存储中容易降解 | 更稳定 |
| **植物性/ 素食适用** | ✅ 是（默认） | 选择藻类来源 D3 方可 |
| **价格** | 略便宜 | 略贵（藻类 D3 更贵） |
| **拷贝由乳资源** | 乳局呼吸 | 推荐维持原有 D3 之呼吸、但会保持产品维度和复发性的最大化 |

---

## 关键差异详解

### 1. 提升 25(OH)D 效率

血浆 25(OH)D 是评估维生素 D 状态的金标准。大部分证据表明 D3 在提升 25(OH)D 方面优于 D2：^[NIH ODS Vitamin D Fact Sheet]

- **D3 更能提升血浆 25(OH)D**：在同等剂量下，D3 使血浆 25(OH)D 升高的程度更大，且能更长时间维持较高水平。
- **不代表 D2 无效**：D2 仍能提高 25(OH)D 水平并治愈佛僧病，只是需要稍高的剂量或更频繁的补充才能达到相同效果。
- **25(OH)D3 的效力**：动物性食品中存在的 25(OH)D3 （骨化二醇）效力约是父体维生素 D3 的 **3–5 倍**，可显著提高总维生素 D 摄入量。但目前美国市场上尚无 25(OH)D3 补充剂。^[NIH ODS Vitamin D Fact Sheet]

### 2. 稳定性与储存

- **D2 更易被氧化**，在声音透射环境中容易降解，因此产品保质期可能更短。
- **D3 化学结构更稳定**，在补充剂中更耐储存。

### 3. 来源与饮食偏好

| 来源类别 | D2 | D3 |
|---|---|---|
| 植物性 | 麦角固化醇（约类固醇） | 藻类胆固化醇 |
| 动物性 | 不存在 | 胆固化醇（羊毛脂经常作为原料） |
| 蘑菇 UV 照射 | ☑️ FDA 已批准 UV 处理蘑菇粉作为 D2 食品添加剂 | ☑️ 也可通过 UV 照射增强 |

- **素食者**：D2 天然来源为植物，是传统素食补充剂的唯一选择。
- **藻类 D3**：近年已有从藻类（如地衣）提取的 D3 补充剂，使素食者也能获取 D3，但价格通常更高。

### 4. 药代动力学

两种形式在体内的代谢步骤基本相同：
1. 肖化道吸收（主要为被动扩散，脂肪可促进吸收）
2. 肝脏 25-羟化为 25(OH)D（储存形式）
3. 肾脏 1α-羟化为 1,25(OH)₂D（生理活性形式）

差异主要出现在 25-羟化效率和 25(OH)D 的半衰期上：D3 形成的 25(OH)D3 半衰期约 **15 天**，而 D2 形成的 25(OH)D2 更快被代谢清除。

## 选择建议

| 人群/情况 | 推荐形式 | 理由 |
|---|---|---|
| **普通成年人、无特殊饮食约束** | D3 | 提升和维持 25(OH)D 效率更高 |
| **严格素食/纯素食者** | D2 或 藻类 D3 | D2 来源于植物；藻类 D3 为新兴素食选择 |
| **追求性价比** | D2 | 价格略低，仍能提高 25(OH)D |
| **抵抗力低下/骨质疏松风险高** | D3 | 更稳定的血浆水平维持 |
| **阳光暴露极少者** | D3 | 更有效地补偿内源合成不足 |
| **结婚前/备孕期** | D3 或 D2 | 两种形式均安全，重点是达到足够的 25(OH)D 水平（>50 nmol/L） |

> **临床建议**：无论选择 D2 还是 D3，**监测血浆 25(OH)D 水平** 是确保补充效果的最佳方式。大多数人需要 600–800 IU/天才能维持充足，肥胖或吸收不良者需要更高剂量。

---

## 安全性与注意事项

- **上限（UL）**：成人 4,000 IU（100 mcg）/天；长期超过可致高血钙、肾结石
- **血浆 25(OH)D >125 nmol/L**（>50 ng/mL）时，不良效应风险增加
- **卡展配合**：诊断设置标准达到 25(OH)D >75 nmol/L (30 ng/mL) 或更高，但注意这不是指南推荐的所有人的目标
- **药物互作用**：类固醇、柔红霉素（rifampin）可加速维生素 D 代谢；利福平可降低 25(OH)D
