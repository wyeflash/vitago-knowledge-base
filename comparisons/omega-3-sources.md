# Omega-3 来源对比：鱼油 vs 磷虾油 vs 海藻油

## 对比目的

Omega-3（EPA/DHA）补充剂市场存在三种主要来源：鱼油、磷虾油和海藻油。它们在 EPA/DHA 比例、分子形式、生物利用度、污染物风险及适用人群上差异显著。本页帮助用户根据自身饮食偏好、健康状况和预算做出知情选择。

---

## 三种来源对比总表

| 特性 | 鱼油（Fish oil） | 磷虾油（Krill oil） | 海藻油（Algal oil） |
|---|---|---|---|
| **主要形式** | 天然 TG、乙酯 EE、再酯化 TG（rTG）、游离脂肪酸 FFA | 磷脂（phospholipids） | 天然 TG（部分含 EPA） |
| **EPA/DHA 来源** | 深海鱼类（沙丁鱼、凤尾鱼、鲑鱼等） | 南极磷虾（Euphausia superba） | 微藻（Schizochytrium 等） |
| **典型 EPA:DHA 比例** | 因产品而异；常见约 3:2 或 1:1 | EPA 较高，但总体含量低于鱼油 | 主要为 DHA；部分产品含 EPA |
| **生物利用度** | rTG/TG/FFA 略高于 EE；所有形式均可显著提高血浆 EPA/DHA | 部分研究显示略高于鱼油，但结论不一致 | 与熟三文鱼中的 DHA 生物利用度相当 |
| **污染物风险** | 加工中去除甲基汞等重金属；优质产品极低 | 南极磷虾处于食物链底层，污染物积累少 | 藻类培养可控，几乎无重金属 |
| **胆碱/虾青素** | 无 | 含磷脂酰胆碱；天然虾青素（抗氧化/保鲜） | 无 |
| **素食/纯素适用** | ❌ 否 | ❌ 否 | ✅ 是 |
| **鱼腥味/反嗝** | EE 形式较明显；rTG/TG 较轻 | 较轻 | 较轻 |
| **价格** | 💰💰 中等（rTG 较贵） | 💰💰💰 较贵 | 💰💰💰 较贵 |
| **可持续认证** | IFOS、MSC、GOED 等 | MSC、CCAMLR 合规 | 素食协会认证、藻培养可持续 |

## 关键差异详解

### 1. 分子形式与吸收

膳食补充剂中的 Omega-3 存在多种化学形式，直接影响肠道吸收效率：^[NIH ODS Omega-3 Fact Sheet]

| 形式 | 说明 | 相对生物利用度 |
|---|---|---|
| **天然 TG（Triglyceride）** | 鱼体内天然存在形式 | 较高 |
| **乙酯 EE（Ethyl Ester）** | 用乙醇替代甘油分子合成 | 略低于 TG/rTG |
| **再酯化 TG（rTG）** | 由 EE 转化回 TG 结构 | 较高，接近天然 TG |
| **游离脂肪酸 FFA** | 水解后的自由脂肪酸 | 较高 |
| **磷脂（Phospholipid）** | 磷虾油中的主要形式 | 部分研究显示略高 |

> **核心结论**：rTG、天然 TG 和 FFA 的生物利用度略高于 EE，但**所有形式均可显著提高血浆 EPA 和 DHA 水平**。实际选择时，形式差异不如每日总剂量重要。

### 2. 鱼油的特点与细分

鱼油是研究最充分、性价比最高的 Omega-3 来源。

**优势**：
- 高剂量 EPA/DHA 产品选择丰富
- 处方级 Omega-3（如 IPE/Vascepa）基于鱼油乙酯，在 REDUCE-IT 试验中证实心血管获益
- 广泛的质量认证体系（IFOS 五星、USP、NSF）

**注意点**：
- EE 形式随餐服用（尤其含脂肪餐）可改善吸收
- 部分人群服用后有鱼腥味反嗝，rTG 或肠溶包衣产品可减轻
- 选择经 IFOS 或类似认证的产品可确保低氧化值和低污染物

### 3. 磷虾油的特点

磷虾油因独特的磷脂形式而备受关注。

**优势**：
- Omega-3 与磷脂结合，可能更容易被细胞利用（磷脂是细胞膜成分）
- 天然含虾青素（astaxanthin），提供抗氧化保护并延长产品保质期
- 食物链底层来源，污染物积累较少

**局限**：
- 每粒胶囊的 EPA+DHA 总量通常低于鱼油（因磷脂分子量较大）
- 价格显著高于鱼油
- 生物利用度优势的研究结果不一致：部分试验显示血浆 EPA/DHA 提升更快，但并非所有研究都支持显著优势

> **NIH ODS 评价**：部分研究表明磷虾油中的磷脂 Omega-3 生物利用度略高于鱼油，但其他研究未观察到差异。^[NIH ODS Omega-3 Fact Sheet]

### 4. 海藻油的特点

海藻油是素食者和纯素食者获取 EPA/DHA 的唯一直接来源。

**优势**：
- 完全植物来源，适合素食/纯素饮食
- 生产过程可控，无海洋污染物
- 提供与熟三文鱼相当的 DHA 生物利用度（小型研究）

**局限**：
- 大多数产品以 DHA 为主，EPA 含量低或不含
- 部分新型产品开始同时提供 EPA 和 DHA
- 单位剂量的 Omega-3 含量通常低于高浓度鱼油
- 价格较高

## 选购建议

| 人群/需求 | 推荐来源 | 理由 |
|---|---|---|
| **追求性价比** | 鱼油（TG 或 rTG 形式） | 剂量高、研究充分、选择多 |
| **需要高剂量 EPA** | 高浓度鱼油或处方 IPE | REDUCE-IT 级别的心血管证据 |
| **胃肠敏感、反嗝明显** | 肠溶包衣鱼油或磷虾油 | 减少鱼腥反嗝 |
| **素食/纯素者** | 海藻油 | 唯一植物来源的 EPA/DHA |
| **关注污染物** | IFOS 五星认证鱼油或磷虾油/海藻油 | 低氧化值、低重金属 |
| **寻求额外抗氧化** | 磷虾油 | 天然虾青素 |
| **儿童/吞咽困难** | 液体鱼油或海藻油（DHA 滴剂） | 剂量可调、易吞咽 |

---

## 安全性与注意事项

- **出血风险**：高剂量 Omega-3（>3 g/天）可能与抗凝血药产生相互作用，手术前需告知医生
- **房颤**：部分高剂量研究（如 STRENGTH）提示补充组房颤发生率略高，但因果性未确立
- **鱼/甲壳类过敏**：鱼油通常对鱼类过敏者安全（蛋白质在精炼中去除），但敏感者仍需谨慎；磷虾油含甲壳类成分，过敏者禁用
- **储存**：Omega-3 易氧化，开封后冷藏并在保质期内用完
